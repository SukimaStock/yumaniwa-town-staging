# ORBIT Web v0.7

- Suppressed browser text selection and copy/callout UI on the full-screen game surface.
- Added `user-select: none`, `-webkit-user-select: none`, and `-webkit-touch-callout: none`.
- Prevented `contextmenu`, `selectstart`, and `dragstart` on the canvas.
- No gameplay, flight physics, landing, or takeoff behavior changed.
