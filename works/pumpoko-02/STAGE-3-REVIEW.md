## 地形変更

STAGE 3の既存3つの崖を維持し、崖②を崖①の直後へ移しました。間の岸を浅いくぼみと上り坂にして、最初の飛行から次の助走へ速度を整える場所にします。

| 項目 | 変更前 | 変更後 |
| --- | ---: | ---: |
| 崖① | x 13040–13200 / 幅160 | 幅・助走そのまま、向こう岸の高さ305→290 |
| 崖①と②の間の岸 | 1740 | 300（.8倍で240px、カボチャ直径約4.17個分） |
| 崖② | x 14940–15120 / 幅180 | x 13500–13640 / 幅140 |
| 崖③ | x 16240–16380 | 完全一致 |
| STAGE 3の長さ | 7360 | 完全一致 |

右入力を続けると最初の飛行が長くなり、短い岸の上り側まで進んでから接地します。この比較例では次の飛行で向こう岸にかすめますが、乗り切れず落ちます。速度を整えると岸の手前から転がり直せます。難しさは崖を広げた結果ではありません。

変更するruntimeは `courses.js` だけ。STAGE 1・2・4・5、全4つの穴、入口・出口の肩、全チェックポイント設定、最終ゴール・エンディング・タイトル、物理・入力・描画・音は基準mainと一致しています。STAGE 3の助走と崖③以降も一致。カメラは無変更、倍率.8のままです。描画と接触は同じHermite曲線・gapデータを使用します。

## 同じ出発状態での操作比較

基準はSTAGE 3のチェックポイントを正常復元した同一の位置・速度・個体・設定です。位置や速度を途中で書き換える補助はありません。以下は60Hz入力／240Hz物理での一例です。時間はSTAGE 3の復元時点から。

| 操作 | 結果 | 観測 |
| --- | --- | --- |
| 右保持 | 崖②で落下 | 崖①離陸vx429、短い岸の奥で接地。8.38秒で画面外落下、9.03秒で復帰 |
| 空中で短く左、その後右 | 2つとも成功 | 約0.18秒の逆入力で受け止め方が変わり、7.45秒で向こう岸の安全な位置へ到達 |
| 離陸前に適度に減速、その後右 | 2つとも成功 | vx329で離陸、岸の手前x13203へ接地。上り坂を使い直し7.57秒で突破 |
| 勢い不足 | 崖①で落下 | 早く減速しすぎて離陸vx276。向こう岸へ乗れず6.68秒で落下、7.33秒で復帰 |
| 停止→逆走→助走し直し | 2つとも成功 | x12986で接地したままvx約−2.9まで停止、x12758まで戻って再加速。11.27秒で突破 |

30・60・120fpsで、右保持と勢い不足は失敗、減速の2種類と停止・逆走は成功しました。途中の停止は実際の逆入力で行い、状態の強制停止・リセットは使いません。

空中の逆入力は開始位置と解除位置を変えた5例×3fpsで成功。成功例の逆入力時間には約0.08〜0.67秒の幅があり、1つの正解フレームに固定されていません。ただし無制限に減速しても越えられるわけではありません。崖①の650単位の助走、短い岸の左側の停止位置からも既存の右入力で再加速・突破できます。

落下後はSTAGE 3の開始地点に0.65秒で復帰。完了済みSTAGE 1・2と2回の交代を保持し、速度・入力をクリアして新しい操作を受け付けます。BGMや導入は再開始しません。

全5ステージの通し例は30／60／120fpsで、それぞれ89.67／87.37／87.16秒で最終ゴールへ着座し、既存の約6.23秒の終幕からタイトルへ戻りました。4回の交代、着座1回、全5ステージ完了、再プレイを確認しています。
