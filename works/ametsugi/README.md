# 雨つぎ

雨どいを指で傾けて、一粒の雨を次の雨どいへ。下の器まで渡す小さなゲームです。
銅色の端か雨どい本体を上下にドラッグします。こぼれたら、傾きを残したままもう一粒。水平に戻すと、途中で水を待たせられます。

五つの屋根を渡ったら雨が止みます。「もうひと雨」では左右が反転します。
音の切替は右上、はじめからは左下。PCでは1〜4で雨どいを選び、左右キーで傾けます。
