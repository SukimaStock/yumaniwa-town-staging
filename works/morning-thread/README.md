# あさのつなぎめ

仮題 / work-id: `morning-thread`

小さな予定を調べて、紙片をつなぎ、自分の朝を動かすゲーム。
家の中の3つの用事から始まり、開店前のモールへ進みます。
最後には、自分が通った時刻と道を一冊の旅の記録に残します。

## 遊ぶ

- 館内図の場所そのものをタップすると、営業時間・用事・つながる通路の札が開きます。
- 「このカードをつなぐ」で手帳の末尾へ紙片を置きます。
- 左の絵を持って上下へ動かすと、他の紙片が場所を譲ります。近づけると小さく吸着し、離すと順番が決まります。
- ↑ / ↓ でも並べ替えられます。× は削除、「線をほどく」は残りの予定を外します。ドラッグは必須ではありません。
- 糸のそばの数字は移動時間。通路がまだつながらない紙片には、たるんだ糸とメモが残ります。
- 手帳の端のSTART「出発印」を押すと、予定が動きます。考えている間は時計が止まっています。
- 館内放送の後は残りの紙片だけを編集し、RESUMEの印で同じ場所・時刻から続けます。
- 失敗しても同じ手帳で組み直せます。「朝をやり直す」でその章をすぐ再開できます。
- 長い旅程や記録は手帳の中を縦にスクロールして読みます。館内図と出発印は同じ盤面に残ります。
- 音は右上でONにできます。無音でも全ての情報が分かります。
- 端末の「視差効果を減らす」に応じ、動きを抑えて紙片と糸の順序を表示します。

プレイ中に使う時刻はゲーム内の整数分です。現実の時計には依存しません。
リロードすると表紙へ戻ります。旅程・旅の記録はこのプレイ中のものです。

## 小さな旅

1. 家の中：コーヒー、洗濯もの、玄関。
2. モール：8:50までにベーカリーのパンを屋上へ。
3. 旅の記録：寄り道や放送も含めた到着の記録と、次の白いページ。

ベーカリーでパンを受け取ると、一度だけ館内放送が入ります。
8:44のリフト便は休止。花屋から屋上への裏通路が使えるようになります。

成立例（放送後の残りの旅程）:

- 中央通路 → エスカレーター → 屋上：8:47到着。
- 食品売り場 → 花屋 → 屋上：一輪を添えて8:48到着。
- リフトで立ち止まった後も、食品売り場 → 花屋 → 屋上で8:50に間に合います。
