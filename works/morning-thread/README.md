# あさのつなぎめ

仮題 / work-id: `morning-thread`

小さな予定を調べて、紙片をつなぎ、自分の朝を動かすゲーム。
家の中の3つの用事から始まり、開店前のモールへ進みます。
最後には、自分が通った時刻と道を一冊の旅の記録に残します。

## 遊ぶ

- 紙の端をポンと触ると、閉じた手帳・少し開いた手帳・開いた手帳を行き来します。端を直接上下へ引いたり、フリックしてもめくれます。
- 館内図の場所を触ると、その場所から札が現れます。時刻と通路のメモを読んで、札を持って手帳へ運びます。
- 紙片を「いま」の場所や別の紙片の少し下へ近づけると、薄い糸が伸びます。あと少しで吸着し、離すと一本の旅程になります。
- 紙片を別の紙片の下へ滑らせると、周囲が場所を譲り、順番を結び直せます。
- 紙片を紙の上端より上へ十分引き、少し待ってから離すと、糸がほどけます。紙片は残るので、また結べます。
- 糸のそばの数字は移動時間。通路がまだつながらない糸には、たるみと「通路のメモ」が残ります。
- 糸の端の小さな木片を右へ引くと、出発印が落ち、手帳が少し下がって朝が動きます。考えている間は時計が止まっています。
- 館内放送の後は残りの紙片だけを結び直し、糸の端から同じ場所・時刻で続けます。失敗してもすぐ組み直せます。
- ドラッグなしでも遊べます。札をタップして手帳へ置き、「いま」か先につなぐ紙片をタップ。選んだ紙片の結び目をタップするとほどけます。糸の端はタップでも出発できます。
- 右上の「操作のメモ」には、場所の情報・追加・前後への移動・解除・再出発・朝のやり直しをまとめています。キーボードでも操作できます。
- 音は右上でONにできます。無音でも全ての情報が分かります。端末の動きを減らす設定にも対応しています。

時刻はゲーム内の整数分です。現実の時計には依存しません。
リロードすると表紙へ戻ります。旅程・旅の記録はこのプレイ中のものです。

## 小さな旅

1. 家の中：コーヒー、洗濯もの、玄関。
2. モール：8:50までにベーカリーのパンを屋上へ。
3. 旅の記録：寄り道や放送も含めた到着の記録と、次の白いページ。

ベーカリーでパンを受け取ると、一度だけ館内放送が入ります。
8:44のリフト便は休止。花屋から屋上への裏通路が使えるようになります。

成立例（放送後の残りの旅程）:

- 中央通路 → エスカレーター → 屋上：8:47到着。
- 食品売り場 → 花屋 → 屋上：一輪を添えて8:48到着。
- リフトで立ち止まった後も、食品売り場 → 花屋 → 屋上で8:50に間に合います。
