# あさのつなぎめ

仮題 / work-id: `morning-thread`

小さな予定を調べて、カードをつなぎ、自分の朝を動かすゲーム。
家の中の3つの用事から始まり、開店前のモールへ進みます。
最後には、自分が通った時刻と道を一冊の旅の記録に残します。

## 遊ぶ

repository rootからHTTP配信し、`/works/morning-thread/` を開きます。

```sh
python3 -m http.server 8000
```

- 下の場所をタップすると、手帳に営業時間・用事・つながる通路が入ります。
- 「このカードをつなぐ」で旅程の末尾に追加します。
- ↑ / ↓ で並べ替え、× で削除。「線をほどく」で残りの予定を外します。
- 左の絵をドラッグしても並べ替えられます。ドラッグは必須ではありません。
- STARTで予定が動きます。計画中・館内放送中には時間が進みません。
- 放送後は未実行のカードだけを編集し、RESUMEで同じ場所・時刻から続けます。
- 失敗時も同じ手帳へ戻ります。詰まったら「朝をやり直す」でその章を即座に再開できます。
- 音は右上でONにできます。無音でも全ての情報が分かります。

プレイ中に使う時刻はゲーム内の整数分です。現実の時計には依存しません。
リロードすると表紙へ戻ります。旅程・旅の記録はこのプレイ中のものです。

## 構成

1. 家の中：コーヒー、洗濯もの、玄関。待つ・並べる・実行する感触。
2. モール：8:50までにベーカリーのパンを屋上へ。
3. 旅の記録：寄り道や放送も含めた到着の記録と、次の白いページ。

ベーカリーでパンを受け取ると一度だけ館内放送が入ります。
8:44のリフト便は休止。花屋から屋上への裏通路が使えるようになります。

成立例（放送後の残りの旅程）:

- 中央通路 → エスカレーター → 屋上：8:47到着。
- 食品売り場 → 花屋 → 屋上：一輪を添えて8:48到着。
- リフトで立ち止まった後も、食品売り場 → 花屋 → 屋上で8:50に間に合います。

## 実装

Engine 0.3.0 / Codea Lite 1.0.0はcanonicalへの参照です。コピーやpatchはありません。
StarterのcreateApp・scene update/draw・Audio baseline・bootstrap順序を使用しています。
ミニチュア描画・時刻進行・lifecycleはEngine、操作カードはnative DOMで扱います。
共有候補はEngineの既存機能に収め、ノード・通路・時刻・イベント・UIはこのfolderだけに置きます。

`model.js` が純粋なルール、`sketch.js` が表示と操作です。
旅程はunique node-id配列。接続は無向edgeと分数で持ちます。
移動、開店待ち、用事、定時便待ちを別phaseとし、整数分tickで実行します。
到着した過去の道はrecord、これから進む道だけがrouteです。

作品登録、施設配置、検索ページ、公開用metadataは今回のDraft範囲に含みません。
タイトルも仮題です。公開前に名前と町内導線を決めます。
