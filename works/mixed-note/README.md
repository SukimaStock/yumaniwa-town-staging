# 日英の下書き · Phase 1

iPhone Safariで、ローマ字と英語を混ぜて書くための小さな試作。

1. 「書きかけ」に英字キーボードで入力する。日本語の直接入力も可能。
2. 候補の語をタップして英字・かな・表記を直す。
3. 「下書きに入れる」。下書きのカーソル／選択位置へ挿入する。
4. 下書きを通常の日本語入力で整え、全文をコピーしてnoteへ貼る。

作品名などは「辞書と修正の記憶」で登録。漢字の自動文節変換は初版に含まない。
下書き・未確定原文・辞書・訂正の記憶はこのブラウザに保存する。
保存不可時は明示する。書き出しは未確定原文も含む。
本文を外部サービスに送信しない。初回読み込み後に変換用の通信は不要（オフライン再起動を保証するService Workerは未導入）。
