# ORBIT Web v2.7.3 — POLISH PASS 1

v2.7.2 の通しプレイ可能な基盤はそのままに、最初の磨き 1〜4 のみ実装。

- 通常HUD / E.V.E. console / HOME Terminal / MiniMap の文字を約2段階大きく。
- 機体のオレンジ色の方向プルームを非表示。薄い青haloのみ残す。
- 右上HUDの ORE / DATA 文字を、コード描画の鉱石 / データ結晶アイコンへ置換。
- VOX採掘tick時に短い火花を表示。
- +3 等の取得表示は維持し、浮動小数由来の端数表示を整数化。
- ORE / DATA の実取得量も整数化。FUEL内部値は従来どおり連続量。

ゲーム進行、RESTORE、Terminal、Ritual、MiniMap性能、着陸可否、燃料切れ演出、E.V.E.専用表示は未変更。
