# なで跡 · Touch Comparison

Feel Studioの「制作中の試作」から「なで跡 · Touch Comparison」を開きます。一つの不変buildで設定だけを分岐し、自分の指やマウスでなでて比べる制作版です。原作品 `works/nadeato/` は変更していません。

## 四つのLIVE調整

| 設定 | 初期値 | 作用 |
| --- | --- | --- |
| 毛が指に追いつくまで | 0秒 | 0はその場で寝る。大きくすると目標の向きへ少し遅れて追いつく。指を離した後も静かに落ち着き、跡を残す |
| なで跡のつきにくさ | 0 | 入力に対して向きが変わる量を減らす。最大でも反応を残す。物理的な指への抵抗や振動ではない |
| 指が触れる幅 | 54 CSS px | 画面上の指幅。なで始めに画面寸法を取り、同じジェスチャー中は換算を固定する |
| 毛の向きによる明暗 | 1倍 | 原典の方向光成分だけを調整。毛の形やなでた方向は変えない |

「触りながら調整」を開いても毛並みの操作は続けられます。LIVE変更では毛根や残った方向をリセットしません。設定をUndoしても、実行中の毛一本ずつの向きへ巻き戻すことはありません。同じ準備から確認したいときは場面を再開始します。

## 同じ場面から試す

- 「何もなでていない面」：seed137、640×560の材料座標と、すべての初期方向から開始。
- 「中央を一度なでた面」：材料座標の(150,280)から(490,280)へ、640×560の基準寸法で一本なで、向きを落ち着かせた状態から開始。逆になでて比べられる。

現在の4設定を保ち、作品側が場面を作り直します。固定跡でも幅と抵抗は現在設定を使用し、追従待ちを完了させた同じ基準状態を作ります。追従時間の違いは、その後の自分の入力で比較します。自由入力は同じ操作の完全再現ではありません。

自由操作の54 CSS pxは画面上の指幅です。固定跡は材料の基準寸法で準備するため、縮小された比較画面では自由操作より跡が細く見えることがあります。画面サイズに合わせて固定場面のレシピを変えず、条件差を隠さない方針です。リサイズは現在のなで動作を終了し、すでに付いた跡と毛の配置を保持します。

元案を残すには「ここから分岐」。比較案を選び「両案をこの場面から」を使います。固定跡では指幅と抵抗による開始状態の差も表示されます。気に入った設定を採用・保留し、作業机JSONで設定・案・場面選択を保存できます。毛一本ずつの途中状態やUndoの操作履歴は永続保存しません。

## 接続と原版との関係

新しい `prototypes/nadeato/nadeato-a/` のmodel/renderer/appがCanvas・入力・RAFを所有します。既存 `bridge-client-v05.js`、host/Records、Scene Replay APIを再利用します。source/HTML/全依存をcatalogでSHA256固定し、旧buildを上書きしません。`play.html`はBridgeなしで原版に近い単体ページとして起動します。音・得点・追加のゲームUIはありません。

原典のseed137、25,012本の毛の根・長さ・色、初期方向、28段階の陰影、タイル描画を維持。元作品の入力では同じ経路もサンプル数により累積量が変わるため、制作版は材料座標4pxごとの再サンプリングに変更しています。初期の見た目と即時反応は原典に合わせ、イベント依存のなで結果まで完全一致したとは扱いません。

抵抗は方向への寄せ量を `1/(1+4r)` 倍にする一つのモデルです。追従は目標方向へ秒単位の指数応答。目標は残り、放置して初期方向へ戻りません。別の物理実装を作らず、まずこの調整で選べるかを作者が判断します。

Studioの場面表示は作品の宣言ラベルとconfigDrivenKeysを利用し、雨つぎ専用の角度・待ち時間を前提としません。保存形式/キー・セキュリティ境界は維持します。既存のLAB内の原作品とFeel Studioの入口を利用し、制作buildを別作品へ重複登録しません。
