# PUMPOKO 02

カボチャに触れる。その内側のような世界へ。

地上では、ころころ。地下では、ぽよん。

最初の地上では、坂で勢いをつけて二つの崖を越えます。ジャンプ操作はありません。落ちたら、その地上のはじまりへ。もう一度左右に触れて、すぐに転がせます。

左右に触れて、カボチャとルタバガの旅へ。穴に詰まった相手を押し出すと、そのまま操作が移ります。地下では、着地に合わせて指を押し直すと強く跳ねます。止まったら、一度離してもう一度。

最後の地上を滑ったら、指をそっと離してひと息。二つの植物が残る景色から、またカボチャへ戻ります。
