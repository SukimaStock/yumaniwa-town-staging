# 小さな背景のアクセント

対象: PUMPOKO 02 / stagingのみ。変更前main: `eed8bc652d005536ba9fbde77692ef1a8df0cbb3`。

雲・草・石を基本にし、鳥と花をより珍しいアクセントとして追加した。背景を埋める装飾ではなく、進むとときどき目に入る小さな自然の気配を目指す。

| 要素 | 描画 |
| --- | --- |
| 雲 | 淡いクリーム色の小さな丸い形。地形より遅い視差と穏やかな流れ |
| 鳥 | 雲より低い頻度で、遠くを横切る小さな2本の翼。控えめな羽ばたき |
| 草 | 低い3本の束。地上の緩い地形にまばらに生え、今の緑になじむ |
| 花 | 草より珍しい小さな紫がかった花。平坦な区間だけ |
| 石 | 暖かい土色の丸い小石。輪郭を強調せず、地中へ埋める |

実行時diffは `world-draw.js` の描画補助と3か所の描画呼び出しだけ。既存の描画本体は完全保持し、画像/音声asset、物理/キャラクター/地形/接触/崖/操作/4交換/チェックポイント/落下影の修正/カメラ/BGM/ゴール/終幕、Engine/Codea/旧版/他作品/productionは変更していない。

配置は固定した疎なworld座標から決め、時間は雲と鳥のゆっくりした動きにだけ使う。新しいゲーム状態や乱数の消費、保存、衝突、イベントは追加しない。雲・鳥は地表より上の空へclipし、石は元の土のclipの内側へ描く。石の中心を空洞/断面の縁からも離す。草花は崖の縁から180単位、穴から140単位を避け、急な斜面には置かない。

冒頭の種・根付き・世界への入り込みには追加しない。通常の転がりに入ったあと緩やかに現れ、最後の接近では薄くなり、ゴール前450単位から着座・最後の構図・タイトル復帰まで従来と完全一致する。

検証:

- 最終版47ケース成功。新アクセント5、落下影/地層/socket/five-stage/バトン復帰40、既存Stage 3/phraseの保護2。旧pixel比較には承認されたアクセントだけをテスト専用に除去して同じ条件を与え、別途fresh-base whole-renderer guardで元の全コードを厳密保護する。期待値や判定の緩和はしない。
- 84画面のサンプルで追加による変化は最大790pixel / 0.274%。31画面は変化なし。描画呼び出しはviewport近傍の固定少数セルだけを対象とし、全ルートを毎フレーム列挙しない。花と鳥は草/雲より少ない。
- 全16崖の両端と全4穴の周辺をNative Canvasのpixelで比較し、縁・周囲の着地空間が完全一致。地下の空洞に石/雲を描かない。接地/ジャンプの影、落下影なし、穴のclipとキャラクターの順序、地層の厚み・色を保護。
- 深くfreezeしたworldへ描画でき、body/checkpoint/stateは変わらない。同じview/timeの出力は決定的。Canvas transformも維持。時間を進めても草と地中の石は動かない。
- 30/60/120fpsの全5ステージでfresh mainと同じ入力を与え、世界の全データ/身体/チェックポイント、Story phase/elapsed/look/view/nurseryを定期比較し、最後まで完全一致。元どおり4交換、最終着座、タイトル復帰。既存の連続失敗→保存バトンlaunchへの復帰、入力のリセット、BGM継続も成功。
- 通し60fpsは88.52秒で着座、94.75秒でタイトル復帰、落下0回。比較素材はこの実際の状態を使う。
- Native Canvasの同じviewでwarmup10回後50回を測定し、中央値は約3.55ms→4.04ms、95%位置の値は4.02ms→4.58ms。ローカル環境の参考計測であり、ブラウザ/iPhone/iPad性能を示すものではない。
