# なで跡

短い毛並みを、指やマウスでなでる小さな作品です。
なでる方向で濃淡が変わり、離すとその模様が残ります。
逆向きになでると、同じ場所の毛並みが塗り替わります。
「毛並みをととのえる」で最初の状態へ。矢印キーでも中央をなでられます。

## 制作メモ · 2026-10-13

- 狙い：本人が三案から選んだ C。短い毛が寝て、指の跡が残る単一の手触り。
- できたこと：毛根ごとの方向と方向光による濃淡。逆なで、模様の保持、タッチ／マウス入力。静かな苔色と生成り。
- 想定との差：物理的な抵抗や実際の柔らかさは視覚で代用。毛は短い線の表現で、写実的な毛皮ではない。再読込すると跡は消える。
- 面白かった点：絵具を足さず、同じ場所の向きだけで明るい跡と暗い跡を描き直せる。
- 次の可能性：実機で触った感想から毛の長さ・指幅・濃淡を微調整する。今回の制作では追加しない。

音・得点・時間制限はありません。staging-only の試作です。
