# PUMPKIN × RUTABAGA · Physics Lab

同じU字地形で、するする転がるカボチャと、ぽよんと跳ねるルタバガを比べる、小さな操作実験です。

- **PUMPKIN**：画面の左・右を押す。斜面を往復し、切り返して勢いをつくる。
- **RUTABAGA**：同じ左右入力で方向を変える。着地に合わせて押し直すと反発が強くなる。静止したらもう一度押して再開。
- **HANDOFF**：右へカボチャを転がす。接触するとルタバガへ勢いが移り、そのまま同じ操作を続けられる。
- **WORLD LOOP**：地上を右へ滑り、穴のルタバガを押し出す。地下では左右で進み、天井のカボチャを下から突き上げる。押した側は穴に残り、抜けた側をそのまま操作。止まったら押し直して再開。地上へ戻ったらRESETで何度でも比べられます。

指を画面中央の向こうへ動かしても切り返せます。PCは←→ / A D。RESET / Rは位置を戻します。調整パネルは開いている間だけ実験を止め、閉じると新しい値で続けます。値はこのページを開いている間だけ保持されます。
