# ORBIT Web v0.8 — HARVEST

## Scope
Adds the first resource loop on top of accepted v0.7 flight / landing / takeoff.

## Locked from v0.7
- DRIFT v0.3 flight physics
- thruster-side touch control
- broad landing zone
- 0.5 s landing lock
- shortened landing presentation
- 1.0 s hold-to-takeoff
- browser copy / selection suppression

## Added
- Automatic harvesting while landed. No harvest button.
- VOX: ore, about every 1.0–1.5 s, +1–2.
- SERA: data, about every 1.0–1.5 s, +1.
- LUMA: fuel, every 0.9 s, +8–12.
- Baseline capacities: Fuel 80/100, Ore 0/30, Data 0/10.
- Tiny one-line resource HUD.
- Small +resource feedback near the pod.
- Finite calibration-planet resource pools; depleted planets dim visually.

## Deliberately not added yet
- Fuel consumption in flight
- Base / home
- E.V.E.
- Echo / Corrupted Logs
- Rare material / credits
- Visit-cap / regeneration economy
- Upgrades, missions, shop, save, repair, story

## Design rule
Landing itself is the harvest action. Stay as long as you want; hold to take off when done.
