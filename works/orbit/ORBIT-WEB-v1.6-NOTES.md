# ORBIT Web v1.6

## Scope
Expand the successful Lv1→2 BASE repair loop through BASE Lv5 without adding a new station UI or changing the accepted flight / landing / launch feel.

## BASE restoration costs
- Lv1 → Lv2: ORE 20
- Lv2 → Lv3: ORE 15 + DATA 3
- Lv3 → Lv4: ORE 20 + DATA 5
- Lv4 → Lv5: ORE 25 + DATA 8

The first 20 ORE milestone is preserved. Later Web costs intentionally use only ORE / DATA because Rare Material is still deferred.

## Interaction
- Short tap while landed at BASE: repair, when resources are sufficient.
- Hold 1 second: launch, unchanged from v1.5.
- No extra station / repair screen.

## E.V.E. progression
BASE level now controls the return / low-fuel / repair language layer:
1. broken English tokens
2. simple English
3. katakana
4. hiragana-heavy Japanese
5. natural Japanese

## BASE visual progression
- Lv2: powered ring + four nodes
- Lv3: structural spokes
- Lv4: wider service ring + eight lights
- Lv5: calm central pulse + completed outer ring

## Calibration resources
The fixed VOX / SERA resource pools were enlarged only so the complete Lv1→5 loop can be tested before infinite-world generation is introduced.
