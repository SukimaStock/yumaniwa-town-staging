# Motion Lab · 動きの実験室

小さな動きを触って、少し変えて、もう一度触る。気になった手触りを「標本」として残せる、SukimaStockの実験室です。

- **引っ張る / Slime**：1本指でつかみ、2本指で伸ばす。PCはShift＋ドラッグで片端を固定。
- **広がる / PuddleMoon**：タップで波紋、なぞって軌跡。月にも揺れが残ります。
- **集まる・逃げる / Firefly**：1本指は「あまい」、2本指は「にがい」。PCはShiftまたはモード選択。

「動きだけ戻す」は設定を残して実験をやり直します。「初期設定に戻す」は調整値も初期状態に戻します。スマートフォンの「手触りの調整」は下部から開閉できます。

標本には設定・名前・一言メモ・乱数シードを保存します。指の軌跡や途中の形は保存しません。ブラウザーのデータを消すと標本も消えるため、残しておきたいものはJSONを書き出してください。保存できない環境では画面に知らせます。

原作の動きと実験室での変更は「原作の棚」から確認できます。Codea原作そのものをブラウザーで実行する機能ではありません。
