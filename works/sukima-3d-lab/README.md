# Touch Lab · SukimaStock 3D 0.3

小さな多面体を、押す。回す。長押しで引く。

20面の少し不規則な立体です。短く触れると小さく沈んで反発し、長く押すと少しずつ沈み、離すと戻ります。
ドラッグで回転し、軽く払うとその勢いが残ります。
面に指を少し置いてから動かすと、その場所を引っ張れます。離すと小さく揺れて元の形へ戻ります。

iPhone・iPadのタッチ、PCのマウスで遊べます。キーボードでは矢印で回転、スペースで押せます。
