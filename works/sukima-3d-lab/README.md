# Touch Lab · SukimaStock 3D 0.5

小さな立体を、眺めて触る。

これまでの16作品に、くぼんだ塊、輪、器、薄い葉、小さな彫刻を加えた展示室です。
触れる立体は、短く押す。ゆっくり押す。回す。長押しして引っ張る。離すと元の形へ戻ります。
新しい5作品は回して眺める立体です。長押しでも形は変わらず、「初期姿勢」で元の向きへ戻せます。

一覧から立体を選び、矢印で別の立体へ移れます。「一覧」で展示室へ戻ります。
iPhone・iPadのタッチ、PCのマウスに対応しています。矢印キーで回転し、触れる立体はスペースでも押せます。
