# Touch Lab · SukimaStock 3D 0.4

小さな立体を、選んで触る。

多面体、石、結晶、種、貝殻、不思議な塊を並べた展示室です。
短く押す。ゆっくり押す。回す。長押しして引っ張る。離すと、それぞれの形へ戻ります。

一覧から立体を選び、矢印で別の立体へ移れます。「一覧」で展示室へ戻ります。
iPhone・iPadのタッチ、PCのマウスに対応しています。矢印キーで回転、スペースで押せます。

[展示室を開く](https://sukimastock.github.io/yumaniwa-town-staging/works/sukima-3d-lab/)
