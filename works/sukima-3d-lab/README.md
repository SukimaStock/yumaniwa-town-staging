# Touch Lab · SukimaStock 3D 0.7

小さな立体を、眺めて触る。

触れる形、回して眺める形、静かに動く形、指で動かす模型。59作品の小さな展示室です。
触れる立体は、短く押す。ゆっくり押す。回す。長押しして引っ張る。離すと元の形へ戻ります。
風車、開閉する板、振り子、スライダー、モビールでは、一部のパーツが動きます。
「一時停止／再生」で動きを止めたり再開したり、「初期姿勢」で向きと動きの始まりへ戻せます。

扉を少し開く。ハンドルを逆に回す。引き出しを途中で止める。可動部分を直接ドラッグして遊べます。固定部分や背景をドラッグすると模型全体が回ります。

一覧から立体を選び、矢印で別の立体へ移れます。「一覧」で展示室へ戻ります。
iPhone・iPadのタッチ、PCのマウスに対応しています。矢印キーで回転し、触れる立体はスペースでも押せます。
