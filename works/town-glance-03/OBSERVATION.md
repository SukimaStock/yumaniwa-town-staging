# Town Glance 0.3 — 予想 → 確認

## Scope

`works/town-glance-03/` の独立した試作。0と0.2はファイルもURLも保持する。
通常の固定2D地図で、目的地を見る直前に一瞬だけ想像する行為を試す。
方向感覚の改善効果・認知の正確さを実装結果から主張しない。

## Experience

1. YOU、駅、公園、川、通りと、ひだまりカフェのカード。
2. 「場所を見る」→「だいたい、どっち？」。YOU付近から軽くスライドし、離すと目的地が現れる。24 CSS px以上の移動は誤タップ防止のみで、角度や誤差を評価しない。
3. 分からないときは「予想せず地図を見る」で同じ地図を表示。
4. 「もう一つの場所を見る」→こもれび書店を同じように確認。
5. 2つの場所を表示した地図で終了。リロードで初期状態に戻る。

予想の線は確認時に消し、記録・正誤判定・比較をしない。街、YOU、カメラの位置・縮尺は全状態で固定。1つ目の店は2回目に残し、新たに知った場所として使える。端末方位・自由カメラ・パン／ズームは実装しない。

店名と架空住所は、通常の場所カードにある情報として添えた。通り名が予想の手がかりにはなるが、「公園の向こう」等の関係を文章では教えない。通り名だけを探す作業や当てものに感じる可能性は観察対象。未知の街・架空店舗での結果を、土地勘のある実生活へそのまま一般化しない。

## Observe without teaching first

操作前に「公園を基準に」など考え方を教えない。計時・集計は観察者側で行い、UIには出さない。無言で使う様子をまず見る。

- 予想をためらう／面倒に感じるか。自発的に軽く指を動かすか。
- 当てる課題・試験と捉えるか。スキップを遠慮なく使えるか。
- 地図が出たとき「あ、こっちか」と分かるか。
- 2回目に公園、駅、川、1つ目の店との関係を自発的に使うか。
- 一度終了した後、普通の場所確認でもこの短い間を使いたいか。

終了後に「予想するところはどう感じた？」「2つ目は何を手がかりにした？」と尋ねる。改善や正答を期待する質問を先にしない。必要なら別セッションでスキップだけの流れと比較する。

## Development verification

`node --check works/town-glance-03/app.mjs`

Playwrightがある開発環境で:
`node works/town-glance-03/tests/browser.cjs`

ブラウザ検査はローカルHTTP + Chromium実行。390×844、375×667、320×568、390×600の縦画面、844×390横画面、1280×900を対象とする。横持ちの小さい高さでは縦スクロールを許可し、操作を潰さない。外部通信・保存はなく、初期表示、タッチスライド、スキップ、2回のみの遷移、固定地図、リロード、キーボード、2本指によるキャンセル、横はみ出しを確認する。

タッチスライドはCDPの連続touchMoveで、実際の接触に近い時間間隔を入れる。瞬間的なmove/endの投入はブラウザの合成click処理を正しく再現しない。

verificationState: **UNVERIFIED**。機械・ブラウザ検査の成功は人間の体験仮説の成功ではない。物理iPhone/Safari、面倒さ、クイズ感、関係を使う思考、長期改善は未確認。
