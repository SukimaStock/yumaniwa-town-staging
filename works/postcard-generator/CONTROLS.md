# 設定の選択

風景・配色・質感は常に表示します。採用された質感は「印刷風」「水彩画風」、従来の2方式は「以前の…（比較用）」として残します。保存値 print-material / watercolor-material / print / watercolor は変更しません。既定は原画です。

既存の設定を「構図」「建物」「色と空」に分け、折り畳まず表示します。0.1の再現選択だけを「以前のバージョン」にまとめます。意味のない組合せは従来どおり無効化し、短い理由を添えます。水辺の輪郭・反射、路地の重なり、対応風景の側面、0.1の制限は変更しません。

設定変更は同seedで反映、「新しい街を生成」は選択を保ってseedを変えます。36枚比較にも質感を表示し、絵を選ぶとその比較時点の設定へ戻ります。URL・SVGmetadata・設定JSONの形式は従来のまま。engine.mjs / renderer.mjs / exporter.mjs / versions/0.1は変更しません。

表現監査：選択に必要なグループ名と無効時の短い理由だけを追加し、説明カードや詩的コピーは置きません。作者の採否・物理iPhone Safariは未確認です。
