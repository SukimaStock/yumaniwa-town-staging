# H3-2 増分観測の原典と制約

`observe.mjs` は研究用であり、本編から import しない。`replayDistilleryOperations` は研究用入力の準備に限って使う。collector 自体は正式操作1件の前後状態と操作位置を受け取り、操作再生を呼ばない。

## 取得元

| 事実 | 正式情報 | 差分の取得 |
| --- | --- | --- |
| 取扱開始 | shop.relations | 配列長以降。酒店・スーパーの店ID＋ブランドID |
| 実納品 | shop.deliveries | 配列長以降。通常納品も観測 |
| 自家販売 | labConnection.town.shipments | 配列長以降、retail の正数売上 |
| 口コミ・問い合わせ・訪問 | labConnection.town.events | 配列長以降、到達の direct を主場面から除外 |
| 客の反応 | player-news.mjs | 正式な決定的表示関数と前回採用状態。新しい実売上だけ評価 |
| 発売 | releases | 配列長以降。発売IDと商品IDを区別 |
| 樽詰め | core.casks | 最大4樽の内部ID差分。表示番号は使わない |
| 仕込み由来 | start / start-usual の still.batch | 仕込みID・世代・年月・操作位置 |
| 世代交代 | generations.completed | 配列長以降、引継ぎ樽・店舗 |

H2のID・文章・情景・分類順を原典 `chronicle-lab/facts-generate.mjs` に合わせる。S4の瓶詰めIDは商品IDだが、H2は発売IDであり置換しない。反応文の private helper は研究用 Node ソース読込で再利用する。正式ファイルは変更しない。将来の統合では正式な増分表示APIへの整理が必要。

## 時間と参照

町の既存イベント本文は正式ゲーム状態にある。別の全文台帳を作らず、町イベントを生んだ操作ごとに e番号の範囲・操作位置・世代・主場面ordinalの月別開始値を保存する。整理済みの到達が後年の参照元になった場合は、正式本文とこの位置索引から同じ事実を復元する。`resolveChain` は同じ発売、年月、操作順、同操作内の前後、欠損と循環を検査する。店・地域の一致はこの因果検査の代わりにならない。

H2の ordinal は抽出クラスの順序であり、町モデルの e番号とは異なる。`materializeTownFact` は同一操作・同一月の可視町事実だけを数え、抽出ordinalを復元する。索引は町イベント本文数ではなく、町イベントを発生させた操作数と月数に比例する。

## 所有と原子性

カーソルは研究側所有の可変オブジェクト。ゲーム状態とゲーム乱数は変更しない。通常進行はカーソルをそのまま進める。一体保存の試験では未確定のコピーを進め、成功時にゲーム・時計・帳面・歩み等と一緒に採用する。失敗したコピーを再利用しない。直前の同一操作の再送は追加なし、飛越し・逆順・異なる操作キーは拒否する。

## 限界

- 完全な創業時点からの収集を前提とする。旧セーブへの移行は対象外。
- 1 callback は正式記録操作1件。複数操作をまとめた前後状態から途中の位置を推測しない。
- 配列は正式モデルの append-only 契約を使用する。全prefixの改ざん検証は一体保存側で行う。
- 正式発売・ブランド参照および商品名の発売回数は発売数に比例する探索がある。履歴全件走査や再生ではないが、発売数に対する費用を計測する。
- 生きた樽・仕込み由来だけをカーソルに残す。発売後の由来は出力済み fill / bottling 事実を保持側で扱う。
- 客の反応は正式モデルの表示上の事実。架空の客や感情を追加しない。
- Node のソース読込 seam は本編APIではない。Safari性能および本編統合は未確認。

`originUpdates` は H2事実本文とは別に、樽詰め時の内部樽ID・仕込みID・仕込み世代/操作・樽詰め世代と、発売時の由来を返す。保持側が採用すれば、現役樽カーソルから整理した後も由来を残せる。`start-usual` は正式な委任仕込みの開始操作であり、手動 `start` と同じく記録する。開始を観測していない場合は、仕込み年月が読めても世代・操作位置を推測せず null と理由を残す。

デパートは `acceptDepartmentInto` が相談受付時に `shop.relations` を作り、未納品のまま相談取消もできる。これを実取扱開始として表示しない。H2同様に通常の shop-start から除き、実際のデパート納品を観測する。
