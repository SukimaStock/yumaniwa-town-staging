# AmberTime 評価 Lab 0.1 — 一本のウイスキーの評価

2026-10-29。調査基準 main: `8bd15572e10b4dc51fca2c1c3cc025668719caab`。Staging専用。本編・既存Lab・保存・経済・Productionは変更しない。

## 1. 評価モデルの構造

一本を各店120人の固定客層に届ける。客ごとに8軸の好み、軸の重み、熟成への関心を持つ。味の相性、相性が合ったときの熟成価値、印象を別々に計算する。全体の支持と強い支持を分け、最高評価一つで店全体を代表させない。

通常画面は一本・店・中央の客の反応・客層分布・理由を表示する。代表客は評価順の中央、最も強く支持した客は別の開閉欄に置く。全員の計算値は詳細で確認できる。次の提案は任意で、高評価のすべてに改善要求を付けない。

客の「印象」は支持と同義ではない。好みに合わない強い個性も印象に残る。後続Labが印象をすべて好意的口コミとして足してはいけない。

## 3. 新しい仮説と式

以下の係数はゲーム比較用の仮説。実際の飲酒者・店舗を測定した値ではない。

`d = Σ(客の軸重み × |風味 − 好み|) / Σ重み`

`fit = exp(−2.65d)`、`gate = clamp((fit − .45) / .4)`

`maturity = .36 × agePotential × ageInterest × gate`

`attentionCost = .24 × agePotential × (1 − ageInterest) × (1 − .4gate)`

`ease = .06 × (1 − rough)`

`score = clamp(.94fit + ease + maturity − attentionCost)`

`distinct = clamp(max(smoke, .85body, wood, vanilla))`

`impression = clamp(.38distinct + .32|score − .5| × 2 + .3agePotential × gate × ageInterest)`

clampは0〜1。scoreが.80以上は強い支持、.62以上は好き、.48以上は中立、それ未満は合わない。支持率は強い支持＋好きの割合。売れやすさや価格の決定式ではない。

熟成への関心が低い人のattentionCostは「この場では気軽さを優先する」という新仮説であり、価格上昇・需要減少・樽の劣化を意味しない。現行熟成関数には過熟劣化がなく、年数で支持が絞られる効果を熟成化学に偽装しない。

各店で4つの嗜好分布を混ぜ、各軸に±.18の個人差を加える。食堂の混合比は .55/.24/.08/.13、バー .25/.25/.28/.22、専門酒店 .15/.22/.31/.32。熟成への関心の中心は .20/.52/.75、個人差は±.55。店同士の分布は重なる。食堂でも長熟を好む人、専門酒店でも短熟を好む人が存在する。

食堂の飲みやすさ・食事を連想する穏やかな嗜好は表現するが、料理や価格の計算は今回固定・対象外。画面にも明記した。食事との相性を検証したと断定しない。

評価文は実際の風味の強さ・好みとの差の符号・評価段階に対応する。「煙が強すぎる」と「もう少し煙がほしい」を区別する。控えめな風味を好む場合も表現する。

## 4. 熟成年数3モデル

比較範囲の20年を1に正規化する。これは本編の熟成上限ではない。

| モデル | agePotential | 特性 |
| --- | --- | --- |
| A 直線 | min(年数/20, 1) | 後半まで同じ速度で変わる |
| B 逓減（初期表示） | min(log(1+年数/3)/log(1+20/3), 1) | 若い段階から差が現れ、後半は緩やか |
| C 段階 | 3年未満 .05、6年未満 .25、10年未満 .45、15年未満 .70、20年未満 .85、それ以降1 | 境界の前後で評価が変わる |

同じ6年・バランス・食堂・seed20261029では、支持率はA68%、B61%、C64%、強い支持はA12%、B15%、C14%。Bの効果が大きくても全員の支持率が上がるわけではない。熟成に関心がある人の評価と、気軽さを求める人の評価が逆方向へ動くため。

実熟成モードは同じ原酒・樽を各年数で `mature` し直す。年数単独モードは基準年（初期6年）の全8軸を固定して表示年数だけ変える。味比較では年数・店・曲線・seedを固定し、店比較では一本全体を固定する。3曲線比較も同じ一本・同じ客層を使う。

## 5. 味の比較

代表サンプルは固定カテゴリの追加ではなく、現行モデルで再生できる仕込みの例。

| サンプル | 麦芽 / 発酵 / 採取区間 / 樽 | 6年時の特徴 |
| --- | --- | --- |
| 甘い香り | ふつう / 長め / 12–40（99分率）/ 1st | 果実 .829、バニラ .367、樽香 .382 |
| 煙 | ピート / 長め / 10–90 / リフィル | 煙 .663、果実 .571、深み .563 |
| 深み | ふつう / 短め / 75–99 / リフィル | 深み .926、スパイス .690、刺激 .332 |
| バランス | ふつう / 長め / 35–70 / リフィル | 果実 .635、穀物 .551、深み .585、刺激 .135 |

「甘さ」は現行モデルの独立軸にない。果実・バニラを中心とする甘い香りの例であり、糖分の再現とは言えない。深みも現行body軸として扱い、科学的複雑さを新設していない。

## 6. 店による違い

seed20261029、B、実熟成。百分率は画面と同じ四捨五入。

| 一本 | 食堂：支持 / 強い支持 | バー：支持 / 強い支持 | 専門酒店：支持 / 強い支持 |
| --- | --- | --- | --- |
| バランス・1年 | 61% / 3% | 40% / 3% | 17% / 2% |
| バランス・6年 | 61% / 15% | 51% / 15% | 38% / 12% |
| 煙・20年 | 23% / 3% | 50% / 16% | 53% / 23% |
| 深み・20年 | 9% / 2% | 24% / 10% | 47% / 21% |
| 甘い香り・20年 | 27% / 3% | 30% / 8% | 23% / 9% |

同じ一本でも反応と分布が異なる。食堂でも深み20年の強い支持はゼロではない。専門酒店でもバランス1年に強い支持がある。

## 7. 短熟と長熟の役割

年数だけの比較（バランス、風味6年固定、食堂、B、seed20261029）では、1年の支持71%・強い支持12%に対し、20年は支持50%・強い支持20%。幅を失いながら一部の評価が深くなる、という仮説を分離して観察できる。

実熟成では風味改善もあるため、すべての長熟で支持が減るわけではない。煙や深みの長熟は専門酒店で支持の幅も増える。短熟は穏やかな風味を気軽に楽しむ客、長熟は味が合って熟成に関心を持つ客に役割がある。資金回転・待ち時間の経済的価値はこのLabで証明していない。

## 8. 最適解への偏りと限界

短熟または長熟の一方が、すべての客・店・指標で最適にはならない。ただし、**バランス型の広い優位が残る**。5seed・2熟成モード・3式・3店・6年数の540比較組で、バランスは支持率398組、強い支持461組、両方359組で最高（同率を含む）。食堂・B・実熟成では全30条件で両方最高。これは客層の中心を穏やかな味に寄せた仮説の影響であり、公平な設計が完成したとは言えない。

専門酒店20年では煙の強い支持23%がバランス21%を上回るが、複数の長熟で最高評価が1に飽和する。後続で最高値だけを評判の入力に使うと差が消える。支持分布・反応の理由・負の印象を保存する方がよい。

中央の客の発言が年数違いでも同じになる場合がある。理由・全体の分布・最も支持する客の反応を合わせて見る構成だが、「次を試したくなる」かは作者の実機体験で判断が必要。採用確定やLab0.2の開始とはしない。

既存フォントのバイナリをローカルへ取得できず、ローカル画面は代替フォント。公開版は既存本編フォントを参照する。iPhone Safari実機、実フォントでの全幅確認、主観的な触感は未確認。ブラウザー検証成功を作者の採用としない。
