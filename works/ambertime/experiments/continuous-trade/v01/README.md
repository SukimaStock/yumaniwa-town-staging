# AmberTime — 取引のつづき Lab 0.1

独立した一画面の操作・継続取引比較Lab。元の `hand-and-place/v073` は変更しない。Stagingのみ・本編未接続。

## 比較する操作
- タップ：瓶→店をタップする。
- スライド：瓶を選択し、店のスライダーで決める。
- ドラッグ：瓶を店まで直接運ぶ。
- 線で結ぶ：瓶から店へ線を引く。

いずれも同じ取引関係を作る。取扱開始後は同じ製法の在庫から月次で自動発送。発売回が変わっても同じ製法なら継続し、在庫切れなら関係を残して一時停止する。別の製法に切り替える場合だけ店へ新しい瓶を置く。

## 操作と観察
店の初回必要本数は仮値。瓶を選んで店へ置いたら「1か月」または「12か月」を進め、関係・発送・品切れを観察する。新しい瓶を作り同じ製法の取引が再開するか確認する。「ログ」で状態をJSON保存できる。

## 限界
本編と独立した仮モデル。価格、正式保存、実際の需要・最低ロット・店の好み・樽・製法・口コミには未接続。数値や取引成立条件を本編の仕様と混同しない。ブラウザを閉じると初期化される。iPhone Safariとアクセシビリティ実機確認は未完了。

今回のLabは操作比較を優先し、作者の試遊後に方式を選ぶ。本編の販売方式・Productionは変更しない。
