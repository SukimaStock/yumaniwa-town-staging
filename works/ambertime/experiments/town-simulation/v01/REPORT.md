# AmberTime｜街と口コミ Lab — 第2段階

## 範囲と終了条件

既存の街・月次処理・口コミ経路を使い、到達、好みに合う反応、実納品による定着を区別する。代表3種類で広まりの違いと出来事の理由を確認したら、作者の採否を残して実装を区切る。名前Labとの接続、本編、Production、保存方式は対象外。

## 調査と変更

| 仕組み | 判断と対応 |
| --- | --- |
| 口コミの到達 | 維持。実納品から有限の伝播情報を作り、経路の遅延・減衰・重複除外を使う。低相性でも届く。 |
| 好みとの相性 | 整理。既存の刺激・原酒香・木香のtasteだけを使う。価格・熟成年数を好ましさへ乗算しない。共通基準0.5以上で好感・紹介・問い合わせ・取扱いの候補になる。基準未満で繰り返し届いても好感を作らない。 |
| 定着 | 整理。実際に好みに合った納品の回数と、その最初・最後の間隔から関係を育てる。以前の不一致納品は継続実績へ流用しない。取扱いだけで定着とは呼ばない。 |
| 偶然の遠距離伝播 | 維持・簡略化。既存客層の発生率、紹介先、待ち時間、同店6か月・年最大4件を使う。発生率へ相性・本数・鮮度・関係を重ねる乗算を削除。相性は到着後の反応に使う。 |
| 取扱い | 維持。関心→遅延した問い合わせ→相性・在庫・方針・抽選→取扱い→翌月以降の納品。自動成約や販売実績には変換しない。 |
| 長期記憶・訪問 | 既存の比較条件として維持。通常は「受け手の反応」を使用。記憶の再浮上や待機中処理からも不一致商品の問い合わせ・取扱いを作らない。興味本位の訪問は好感とは別。 |
| 通常画面 | 内部の認知・関心・関係の点数を削除し、短い状態を表示。最初の到着と、同じ場所・商品で年に一度までの好感・訪問・問い合わせ等を見せる。日々の納品・記憶・重複到着は通常ニュースから外す。 |
| 完全履歴 | 維持。「すべての記録」や種類別表示、発生元参照、JSON、要約、途中設定、シード、再現機能を残す。ニュースの整理で計算結果を削除しない。 |

通常表示の「少しずつ定着」は、実納品による関係0.18以上かつ現在の関心0.04以上。「好みに合う反応」と「取扱い」とは別の判定で、品質点ではない。待つだけで関係は育たない。

比較用商品は既存3種類の風味を使うが、このLab内だけ準備期間24か月・価格30に統一した。初期在庫も選択商品24本で統一し、以後18か月ごとに24本を仕込む。同じ供給条件で風味を比較するための仮データであり、長期熟成品が同期間でできる製造モデルではない。元のReputation Labの定義は変更しない。

## 代表3種類の結果

シードは着手時に固定した `20261021` と `42`。全例、混合配分・受け手の反応あり、同じ街・同じ24本から開始。10・30・100年で記録。100年の生産1,608本、納品1,200本、在庫408本は全6例共通。途中の納品先は取扱いの結果に従って変わる。

| 商品 | 好みに合う反応が出た場所 | 100年の取扱先数・定着先数 | 偶然の紹介 |
| --- | --- | --- | --- |
| 原酒香が豊か | 酒店・食堂・専門酒店、食文化圏・飲食のつながり | 5〜6先／5〜6先 | 43〜47件 |
| 力強い | 食堂・飲食のつながりが中心。シード42では一部のバーにも反応 | 5〜6先／4〜5先 | 29〜43件 |
| 樽香が豊か | 海外の熟成酒文化圏。地元では好みと合わない | 2先／1先 | 32件 |

取扱先数には開始時の町の酒店を含む。樽香商品の地元酒店は初期の取扱先のままで、好感・定着は得ていない。100年後も全地域が同じ好感・定着状態にはならない。原酒香と力強い商品の重なる場所は多いが、専門酒店やバーでの反応、成立時期、関心の残り方が異なる。店をすべて開けることを成功条件にはしない。

名目値では、力強い商品と食堂の相性は約0.80、樽香商品とデパートは約0.94。バーやスーパーは代表値では3商品とも0.5未満。仕込みごとの既存の小さな風味差で、境界付近のバーに反応が生まれる例がある。特定の店へ必ず届かせる調整やシード探索はしていない。

## 画面に出る出来事

シード20261021では、4年6か月に町の酒店の発信者から海外の熟成酒文化圏への紹介が生まれ、4年7か月に口コミが到着する。原酒香商品では「この土地の好みとは合いませんでした」と表示し、到達を人気と同一視しない。樽香商品では同じ土地で好みに合う反応が生まれる。

樽香商品は、このシードで50年1か月に海外から輸入方法の問い合わせ、51年5か月に取扱いへつながる。同じ商品でもシード42の成立は24年8か月。取扱いの前から海外へは届いており、届く・好まれる・取扱い・定着を別々に確認できる。

通常ニュースは100年で115〜475件、月最大2〜4件。原酒香・力強い商品で主な出来事がない最長期間は1年3か月〜1年6か月。樽香商品では6年6か月〜6年7か月残った。反応先の少ない商品にも毎年成功を保証する調整はしない。再生で待つ感触が長すぎないかは作者の確認事項。10・30・60・100年の既存操作で長期結果を観察できる。
