# 手札と場 Lab 0.7.1 — 棚と小窓の整理

v07のゲーム処理を直接読み込み、棚と小窓の表示だけを減らした独立Lab。本編・v01〜v07・保存形式・Productionは変更していない。基準mainは `19b4bfd8bda2ae5b01ce50fda172158a6f4ba6d3`（PR #629）。実装前にFull Plan Lockを固定した。

## 変更

棚には瓶、短い名前、利用できる本数だけを表示する。同じ製法の発売回が複数ある場合に、発売回と月齢を添える。詳細では元の発売回IDと熟成期間を引き続き確認できる。

瓶を開くと、名前・月齢・主な風味・在庫と行き先を表示する。行き先を選んだ後に数量と短い確定ボタンを表示し、初期の行き先一覧を畳む。戻ると行き先を選び直せる。数量の入力や「全部」では入力欄を作り直さない。主な風味は「個性と仕込み」に畳み、初期表示には重複させない。

通常の在庫元選択欄は置かない。Cで店へ渡す場合だけ「未販売分から渡す」を明示的に選べる。選ぶ前は手元だけを使い、混合在庫の自動補充は加えていない。直接納品はv07の原子的な `retail-deliver` を利用する。

取扱店は「店を選ぶ→一本を選ぶ→数量→確定」と進む。選択済みの店を再び行き先として選ぶ操作を省く。商品候補の先頭には、その店の現在の希望を残す。棚から始める場合も同じ確定関数を使う。結果は小窓に一文だけを表示し、背景へ重複表示しない。

既存の美咲フォント、瓶・樽・蒸留器、部屋と小窓のCSS、右上の閉じる・右下の戻るを読み取り専用で利用する。

## 操作・高さ・スクロールの比較

390×844px、Chromiumの同じ環境で、v07とv071を実際のDOM操作で比較した。以下はクリック・値入力・select選択をそれぞれ1操作として数え、閉じる操作は含めない。実機キーボードの打鍵数ではない。

| 場面 | v07 | v071 |
| --- | ---: | ---: |
| 棚から自家販売へ3本（初期数量） | 2（瓶・確定） | 3（瓶・行き先・確定） |
| 棚から手元の2本をレストランへ | 3（瓶・行き先select・確定） | 3（瓶・行き先ボタン・確定） |
| 店から未販売分2本を直接納品 | 6（店アイコン・店・届ける・一本・在庫元select・確定） | 5（店アイコン・店・一本・未販売分ボタン・確定） |
| 初期商品小窓の高さ | 627px | 443px |
| v071行き先選択後の高さ | — | 489px |
| 小窓内部の追加スクロール | 0px | 0px |

操作数は初期小窓に数量を出さないために1操作増える経路もある。今回の目的は操作数の最少化だけではなく、最初に選ぶ対象を行き先へ絞り、数量入力を安定させること。店経由は一画面分の選択を省いた。

360・375・390pxの各幅でも、初期443px、数量選択489px。内部の `scrollHeight` と `clientHeight` は一致し、追加スクロールはなかった。実測値は `tests/evidence/browser-results.json`。画面サイズはブラウザviewportであり実機Safariの測定ではない。

## 計算・ログの維持

新しいモデルは作成していない。`../v07/model.mjs` を直接importする。

実際のv07画面とv071画面で、同じ発売回を選ぶ→4本を自家販売へ配分→レストランへ未販売分2本を直接渡す、を実行した。各段階でsession全体が完全一致した。内部のv06操作・観察記録と外側のv07操作ログも同じで、schemaは `ambertime-hand-and-place/0.7` のまま。

UIの表示切替や行き先選択はモデルの操作を追加しない。在庫元を選ぶだけではゲーム状態を変更しない。失敗時の原子性・売却済み在庫の保護・ログ再現は既存v07の10テストで確認し、v071で別のルールを再実装していない。直接納品もv07の複製→回収→納品→検証→一括反映をそのまま利用する。売れた分・店へ渡した分の回収や、手元と未販売分の暗黙の混合は行わない。

## 検証

- v07アダプターの関連10テストとLifecycle24テスト、計34テスト成功。
- 360/375/390pxの棚・小窓・通常配分・未販売分直接納品・取扱店からの入口・戻る・発売回の識別を確認。
- 数量入力中の入力要素identityとキーボードフォーカスが維持されることを確認。
- 仕込み済み樽を2か月進めて瓶詰めし、販売室へ戻り、同製法の第2回を選べることを確認。続けて1か月の第3回を瓶詰めし、棚のページ送りと異なる月齢の選択を確認。棚名は旧128pxから各スロット内の108pxへ整理し、補助行が次の棚やボタン範囲に衝突しないことを計測。
- v07とのsession全体一致、v07schemaの維持、JSエラー0を確認。
- Lifecycle生成と検査、Scope→Risk→Impact、構文・差分確認を実施。必須CIと最終公開SHAはPRへ記録する。
- 実装担当以外（root）のapp/CSS読み取りレビューを受け、風味の折畳み、商品候補への希望表示、旧128pxラベル枠の整理を反映した。
- 表現監査6点を確認。操作説明の重複と常時表示の在庫元欄を減らし、必要な出所情報・製法・履歴は詳細に残した。

共有画像8枚（IMG_6259〜6266）について、Library上で先頭5枚の画像ファイルを特定したが、この実行では画像本体のローカル取得・視覚確認を完了できなかった。画像を確認済みとはしていない。比較は同じviewportで新たに撮った旧v07とv071のブラウザ画像を用いた。

包括E2E、実機Safari/VoiceOver、作者の触感・採否、発熱・電力、Productionは未確認。本編へ統合しない。
