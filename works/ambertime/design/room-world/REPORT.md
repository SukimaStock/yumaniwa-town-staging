# AmberTime — 三室を同じドット絵の世界へ

Stagingのみ。背景・設備・物体・操作窓を三室で揃え、本文・数値・操作ラベルはHTMLの通常フォントで表示する。

## 描画の共通ルール

- 物体は1マス3 CSS px。石・木・銅・金属・青い窓の少数色を共通化。
- 石壁と木床の上に柱・棚板・作業台を置き、樽・受け器・瓶の底を接地。空いている位置も残す。
- 窓とボタンは明るい3px枠、深青の面、暗い影。長い履歴や詳細は窓内で読む。
- 四樽の容量、商品4件ずつのページ送り、現在の製造・販売・担当者・製法を維持する。

## 三室の変更

- **貯蔵庫**：二段の木棚に四つの位置を設ける。樽の選択表示は物体の周囲に置き、選択した樽の窓へ残量・状態・試飲・比較・瓶詰め・委任をまとめた。試飲時は棚を一段にし、三指標・風味タイプ・短い風味文・前回の印を維持。年数と重複する試飲見出しは読み上げ用に残した。
- **蒸留室**：銅の蒸留器と透明な受け器を木の作業台へ置き、採取量・刺激・原酒の香り・開始／抽出終了を操作窓にまとめる。担当者の費用・製法・依頼・実行できない理由も保持。
- **販売室**：同じ木棚に瓶を置く。空棚と商品4件ずつのページ送りを維持し、長い銘柄名は折り返す。価格・販売先・味・委任・履歴は既存の詳細窓から操作する。

新しい `room-object-art.mjs` は蒸留器72×48、グラス12×18、瓶12×28の整数矩形を描く。本編の樽は前段階の16×16素材を継続使用。表示はいずれも3倍。液色の閾値・不透明度、受け器の採取量、既存の注ぐ反応・蒸留中の反応を維持した。瓶・ラベルの選択も残した。旧版と終了試作が参照する素材ファイルには差分がない。

窓を閉じる操作は表示だけの状態とし、保存・時計・製造処理を呼ばない。閉じた後に新しく樽詰めした場合は、その樽の窓を開く。商品詳細を開いた際の棚の再描画で失われるフォーカスは、同じ商品を識別して復帰させる。依頼確定で部屋が変わった場合は描画完了後に表示中の操作へ戻す。

## 検証結果

- まず貯蔵庫だけで、ゼロ・一・四樽、選択・閉じる・再選択、試飲・比較・瓶詰めを実画面で確認。その後に残る二室へ展開した。
- 既存単体テスト **567/567**、新素材の整数図形・接地・旧液色境界と不透明度・瓶形／ラベル・既存反応のテスト **5/5** が成功。
- 新しい `tests/room-browser.mjs` は **360×740・390×844・1280×900** で成功。実値との一致・表示寸法・主要操作の位置も確認。36状態の画面情報、15枚の画面を記録した。
- 既存 `compact-browser.mjs` も同じ三幅で成功。試飲・比較・瓶詰め入力保持・委任中の停止／復帰・販売先選択・6商品のページ送り・帳面／製法・旧保存・世代交代後・破損保存の扱い・文字拡大を回帰確認した。
- 新ブラウザ検証では、瓶詰め実行、価格選択・販売開始・翌月の実売、商品詳細の三ゲージの開閉も確認。表示だけの窓開閉・比較・販売先切替で保存が変わらないことを照合した。
- 初期（最初の樽1か月）・中期12か月・長期72か月を、現行の公開モデル操作で生成。長期の資金は実際の製造・販売で確保し、年数・資金・風味を直接注入していない。
- 主要物体は等倍の縦横比、整数3倍、`crispEdges`。実画面でも液体・輪郭・棚と作業台への接地を目視した。CSSの旧選択背景、旧グラスの幅指定と変形原点を調整し、旧UIの表示が新しい物体へ混ざらないようにした。
- 操作対象は44px以上。通常文字、キーボードでの樽・商品選択、窓の閉じる→対象へ復帰、商品から依頼確定→新しい部屋への復帰を検証。2倍の文字と高さ430pxの入力画面でも必要な操作にスクロールで到達できる。
- 保存キー、製造・乱数・熟成・経済・契約・製法・雇用・世代交代のモデル、終了済み試作、共有ファイルに差分なし。v17の元保存はそのまま残り、v18への読込後・二代目の再読込は一致。試作保存の保持も確認。
- 独立レビューで描画・既存ルールとの分離を確認。フォーカス復帰の部屋切替タイミングについての指摘は描画後の復帰へ修正し、通常の商品詳細と依頼確定の二経路を回帰検証した。
- 表現監査：装飾コピーや新しい説明・香りアイコンを増やしていない。必要な名称・金額・条件・保存エラーは維持。

390×844とPCでは通常三室がビューポート内。360×740では主要操作は、蒸留開始の下端約467px、貯蔵庫の瓶詰め約695px、試飲の瓶詰め約730px。四樽選択窓や担当者の情報を出した状態では、帳面・保存など下部の入口へ約47〜93pxのページスクロールが残る。文字やタップ領域を縮めず、主要操作を先に配置したため。履歴・多数の商品・長い銘柄・文字拡大・入力中は必要なスクロールを許容し、固定高で切り落としていない。

実機iPhone Safari、OSキーボード、OS文字拡大、実物のタップ、スクリーンリーダーは未確認。ブラウザでの再現と作者の実機での見た目・触感の判断は区別する。
