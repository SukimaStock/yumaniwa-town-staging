## 正式モデルと状態の区別

| 段階 | 正式な意味 |
| --- | --- |
| 申し出 | `shop.offer` / `pendingOffers`。まだ取扱関係はない |
| 確認 | `noticeShopOffer` が `notified` と通知operationを保存。取扱関係はない |
| あとで・閉じる | 確認済み申し出を残す。新しい正式操作はない |
| 取扱開始 | `acceptShop` が店×銘柄のrelationとstartedMonthを追加。次の申し出へ進む |
| 配置 | 現行は手元の瓶を店の棚へ割当。在庫の場所が変わり、現金・実売・納品履歴は増えない |
| 実売 | 翌月以降、配置済みの商品から月次計算。在庫・現金・実績を正式処理で記録 |
| 辞退 | `declineShop`。同店・同銘柄は12か月の再申し出待ち。後続queueは維持 |

取扱開始に新しい契約期間・最低納品義務・違約条件はない。通知と承諾を別のoperationとして維持した。

| 発生条件 | 酒店 | スーパー |
| --- | --- | --- |
| 銘柄の直販売累計 | 40本以上 | 80本以上 |
| 売れた発売回 | 2回以上 | 3回以上 |
| 銘柄経過月 | 2か月以上 | 2か月以上 |
| 追加条件 | 既存の評判条件 | 評判条件＋12か月以上熟成の適格な在庫 |

既存関係なし、初期待機3か月、発生間隔6か月、辞退待機12か月、酒店→スーパー→デパートの順序は変更なし。条件の実装正本は `shopEvidence` / `maybeStockistOffers`。

現行store-marketではスーパーも1本から配置できるため、旧納品条件10本を流用しない。market-rulesの販売計算はSHOPSの月10/20本上限を使わないため、その上限表示を省略する。市場ルール未採用のstore-marketでは既存の月10/20本を維持。旧自動発送モードだけ自動発送を案内し、それ以外は販売室から届ける案内を出す。正式な最低本数・需要・販売機会・価格は変更していない。
