# 0.7 時間・保存・検証

## 時間の意図と一時停止

通常は約6秒で1か月。`userPaused` はプレイヤーの停止操作だけが変更する。試飲、確認ダイアログ、未解決の判断、非表示タブ、保存失敗、資金予約による停止を別の blocker とし、解除後は元の意図へ戻る。複数判断は最後の判断まで停止する。情報用の帳面、通常の部屋移動は停止しない。

100ms の一つの dispatcher が蒸留と月次進行を扱い、generation と expectedMonth で古いコールバックを拒否する。非表示中はタイマーを解除し、復帰時に経過時間を足さない。3か月送りも一月ずつ確定し、判断・試飲・部屋移動・非表示で中断する。手動停止中の3か月送りはその範囲だけ進み、終了後に停止へ戻る。

年月、資金、現在の維持費、月の進行線、進行状態、操作を小さな上部 sticky 領域へ配置。抽出の進行線は蒸留器の横へ分離した。旧CSSにある独立した月バーのループアニメーションは0.7内の優先度で無効化し、dispatcherの実際の月進度だけを反映する。旧来のグラス描画キャッシュと、抽出上限99で明示的な停止を待つ操作は維持する。短い操作通知も上部へ移し、判断だけ native dialog で止める。

## 保存・比較経路

- 新しいキー: `sukimastock.ambertime.economy.v2`。
- 外側 `{version:1,game:<economy version2>,userPaused:boolean}`。経済状態は厳密な操作再実行で検証。意図を保存し、試飲・判断は game 内の状態から停止を再構成する。
- 旧キーは読み書きしない。0.6 は `v06.html`、0.5・0.4・初期版は既存リンクから続けられる。資金・記録の合算や無理な移行はしない。
- 壊れた保存・未来形式・他タブ競合・保存不能は上書きせず停止。保存再確認後は元の時間の意図を尊重する。
