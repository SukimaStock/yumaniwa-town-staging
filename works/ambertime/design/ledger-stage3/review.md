# 帳面 第3段階 — 取扱店

基準: main 5d6758831422bc516c659ca42402dc17ddf364be（PR #569）。Plan Lock 1393faaddbf323419b1d18b7836736fe940f5da27d3178a8c7aacd93a71f014a。

SHOPS の店舗IDから短い一覧を作り、選択した店舗の開始・実納品累計・入金・年月順明細を表示する。20件単位。発売回はPR #565の共通詳細へ接続し、parent / details / scroll / focusの既存復元を利用。今月の注文・未発送は帳面から外し、既存店舗管理は維持。以前の卸取引は独立した折りたたみに保持。

数値の正本は shop.deliveries の正の実納品。入金は明細ごとにセント換算して加算。releases / products / adoptionsのミラーを加算しない。デパートの採用は deliveryId で対応する実納品に付加するだけ。採用リンクのない旧デパート納品は通常納品として残す。デパートrelationは相談受付から存在するため「関係開始」と表示し、初回納品と区別。相談・承認翌月待ちは読取専用、取消は既存画面。旧v12の shopId 欠損だけ既存契約どおり町の酒店とし、開始年月・金額などを他の値から補完しない。未取扱いに架空の0本・£0実績を表示しない。

## 将来の拡張

一覧・詳細は店舗数固定の分岐を持たず、SHOPSと記録中の店舗IDから生成。現行の通常納品と採用付加情報を分け、記録にある未登録IDも独立表示する。飲食店等は既存定義へ追加できる。コラボ取引は通常販売へ混ぜず、実装する段階で別取引種別の契約を設計する。今回、新店舗・分類・保存項目・取引モデル・需要式は追加しない。
