# 美咲3書体の実描画比較

推奨は **美咲ゴシック第2を本文・数字とも同サイズ** で使用し、通常ゴシック用の数字24→32px補正と下げ位置を外す方式です。第2は数字そのものが7ドットの高さで、拡大せず日本語と近い存在感になります。字形や縦横比の加工は不要です。

同じ24 CSS pxでCanvas・HTMLを比較しました。DPR1では数字0・6・8・9の実際の黒い部分が通常ゴシック／明朝で15px、第2で21px。日本語「年」は3書体とも21pxです。第2の£・Lも21pxで数字に揃います。数字の字送りは3書体とも12px。第2へ移行すると、従来32pxへ拡大した数字の字送り16pxから12pxへ戻ります。

| 24px描画時 | 通常ゴシック | ゴシック第2 | 明朝 |
| --- | ---: | ---: | ---: |
| 0・6・8・9の黒い高さ | 15px | 21px | 15px |
| £・Lの黒い高さ | 18px | 21px | 18px |
| 年の黒い高さ | 21px | 21px | 21px |
| バの黒い高さ | 21px | 21px | 18px |
| 数字の字送り | 12px | 12px | 12px |

DPR3の実画素はそれぞれ上記の3倍。独立Canvasへ整数座標で描いた0・6・8・9、£、句読点、L、漢字、仮名では中間アルファ値を検出していません。0・6・8・9は第2の縦長の字形で内部の区別を残し、小数点と区切りカンマも元の字形で表示されます。Canvas・HTMLとも指定7文字列の全文を保持し、異常な欠字はありません。第2の収録は7,170字で、通常版／明朝7,171字との差は可視空白記号U+2423「␣」のみです。𠮷・髙・﨑・絵文字・éは3書体とも未収録のため代替フォントを使います。

数字だけでなく、バーボン／リフィルの仮名も第2で形と位置が変わります。第2の数字・一部仮名はベースラインから上へ7ドット、漢字は下へ1・上へ6ドットです。この元の位置関係も比較画像に残しています。通常版の数字補正用下げ位置を引き継がず、まず同じベースラインで統一するのが適切です。
