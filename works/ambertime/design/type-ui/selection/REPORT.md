# 選択表示の実画面比較

**塗りなしの白い輪郭を推奨します。** 元の黄枠＋青い面より色の主張を減らしつつ、選択した物の範囲を保てます。壁や棚は枠の内側でもそのまま見え、物体の色を変えません。

| 比較案 | 実画面で確認した違い |
| --- | --- |
| 旧：黄枠＋青い面 | 小さい物体の周囲で面色の主張が強い。青が背後の壁を隠す |
| 現：白い輪郭・塗りなし | 選択範囲が明確。白は黄より控えめで、物体の周囲を確認しやすい |
| 白い小さな下向き三角 | 壁と物体の見える範囲を最も広く保てる。ただし瓶の上では印が小さく、視線を外すと見落としやすい |

390×844・DPR3の実際のゲームで、たると瓶を通常操作で選び、小窓を閉じた状態を比較しました。計6画像は同じ座標の画面切り抜きです。選択部の描画だけをテストHTTPサーバーの応答時に置換し、ゲームのファイル・モデル・保存形式は変更していません。表示は`aria-pressed=true`の既存選択状態に従います。

- たる：`old-cask.png` / `outline-cask.png` / `arrow-cask.png`
- 瓶：`old-bottle.png` / `outline-bottle.png` / `arrow-bottle.png`

再現：`../../../tests/type-ui-selection.mjs`。公開モデルから作る既存fixtureを使い、通常のクリックで選択→閉じるを実行。6ケースでページエラーなし、撮影前後の保存文字列一致、実行前後のCanvasソースSHA一致を確認しました。詳細は`results.json`。

白枠は選択状態、黄色のフォーカス線は現在のキーボード操作先という別の役割です。この比較は選択の見た目を扱い、Tab移動とフォーカス移動の動作確認はメインの回帰検証へ分けています。実機Safariでの触感・視認性は未確認です。
