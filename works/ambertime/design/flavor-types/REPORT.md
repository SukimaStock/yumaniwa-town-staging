## 判定

表示専用の純粋関数 `flavorType(profile)` を試飲・樽比較・ボトル詳細で共用する。保存項目、乱数、パラメータ・経済・店・製法・雇用・世代の処理は変更しない。熟成中は現在の試飲／樽、ボトルは発売回に記録されたprofileを使う。過去の製法には熟成後のタイプを付けない。三指標が全て有効でない旧記録は判定なし。

以下の順で最初に一致するものを採る。r=刺激、c=原酒の香り、w=木の香り。優劣・品質点ではない。

| 表示 | 条件 |
|---|---|
| 木の渋みが強い | w>.85、またはw>.66かつw≥r |
| 若く力強い | r>.60、w≤.66 |
| 樽香が豊か | r≤.27、.40<w≤.66、w≥.75c |
| 果実香が豊か | r≤.27、c>.60、w≤.36、c−w≥.30 |
| 軽やか | r≤.18、w≤.25、c≤.52 |
| 果実と樽香が重なる | r≤.27、c>.60、.40<w≤.66 |
| 刺激と香りが重なる | 上記の強い特徴を付けにくい中間状態 |

各強い特徴は組み合わせと差を見る。w>.85は既存の「乾いた木の苦みが余韻を覆う」の保護を最優先する上限例外。果実香と樽香の競合は控えめな中間表現へ渡す。.36〜.40などの幅を持たせ、微差だけで強い特徴同士を切り替えない。直前状態を記憶するヒステリシスや量子化を使わず、同じ値は全画面で同じ結果になる。閾値を跨ぐ任意の微差で絶対に変わらない保証はない。実軌跡で120か月に3〜6区間、294/1120軌跡に1〜2か月だけの中間区間が残る。初案の323から減らしたが、これをゼロと報告しない。

「軽やか」のうちr≤.12、.05≤w≤.20、.35≤c≤.57のときだけ「軽やかなアイリッシュを思わせる口当たり」を添える。実際には軽やか判定のc≤.52も適用。三指標から判断するスタイルの一部の連想で、産地認定・製法・実在銘柄の同定ではない。

## 一次資料（2026-10-18確認）

- [Jameson公式](https://www.jamesonwhiskey.com/en/our-whiskey/jameson-irish-whiskey)：滑らかな口当たりのスタイルの例。国全体への一般化や、この製法の再現という主張はしない。
- [Bushmills公式](https://www.bushmills.eu/whiskeys/original/)：軽いグレーン原酒と滑らかなブレンドの説明。ゲームにない個別の香りは推定しない。
- [Irish Whiskey Association / Drinks Ireland](https://www.ibec.ie/drinksireland/irish-whiskey/campaigns/depth-and-diversity)：Irishには複数の異なるスタイルが存在する。軽やかな一方向の連想に限定する根拠。
- [Nikka公式](https://nikka.com/en/brands/yoichi_miyagikyo/products/)：同じ国内の余市の力強さと宮城峡の繊細さを説明。「繊細＝ジャパニーズ」の対応は見送る。
- [Jim Beam公式](https://www.jimbeam.com/bourbons/jim-beam)：木香に加えバニラ・キャラメル等の組合せ。現行三指標はその組合せを区別できず、「バーボンを思わせる」も見送る。樽の種類を分類入力に使わない。

この対応はゲームの解釈ルールであり、一次資料に数値閾値が載っているという意味ではない。煙・ピート・潮気・特定果実・シェリー香を付け加えない。ゲーム画面に銘柄名、国旗、産地バッジ、ランク、長い注意書きを追加しない。

## 実到達分布と代表例

`node works/ambertime/design/flavor-types/distribution.mjs`で再現。8シード×抽出30〜99×2樽を実際の公開手動操作で作り、公開の熟成関数で0〜120か月追跡した135,520状態。熟成は実モデルの物理追跡であり、全ケースの資金・維持費を賄う経営シミュレーションではない。各発売回の時間固定は別途実際の瓶詰め・月進行で検証する。

| タイプ | 状態数 | 比率 |
|---|---:|---:|
| 木の渋みが強い | 68,880 | 50.8% |
| 刺激と香りが重なる | 23,709 | 17.5% |
| 果実と樽香が重なる | 20,885 | 15.4% |
| 果実香が豊か | 10,106 | 7.5% |
| 樽香が豊か | 6,854 | 5.1% |
| 若く力強い | 2,607 | 1.9% |
| 軽やか | 2,479 | 1.8% |

アイリッシュ連想は273状態（0.20%）。長い熟成を均等に含むため、木の渋みへ偏る。プレイ中の出現確率ではない。若い状態の判定は中間・若く力強いが中心。現行のaroma-aモデルでは抽出時の香りは途中でピークを迎え、その後は薄まるため、旧線形モデルの分布を使わない。

代表例はすべてシード1、表示値はr/c/wの順に丸めた参考値。実判定は丸める前の値を使う。
