# 時間バー・販売室・予約アイコンの表示整理

基準: main `b59809484006fbf6e3baa02fb5f5e474ab3d2796`（PR #560）。共有画像 IMG_6171.png を参照。

- 時間パネルと旧バーを撤去。年月枠直下 x6 / y45 / 幅348の位置に、画面上2 CSSpxの進行線を描画。色は進行 #c5b687 / 未進行 #353947 を維持。線専用の枠・影・背景パネルなし。
- 年月・世代・資金枠は維持。再生停止は表示33×33、操作領域45×45、従来位置のまま。
- 販売室は商品名を省略。本数は瓶の左上、発売年月と販売状態は瓶の下、通常文字サイズ20で中央配置。長い年月は年/月で折り返す。ブランド・発売履歴・アクセシブルラベルは維持。
- 予約アイコンは樽の右側、樽端から論理6px空けて配置。既存7×7パターンを3px単位、21×21で使用。時期指定・在庫連動・停止中の形と色を維持。予約なし・完了済みは表示しない。

## 比較と確認

[電話相当の変更前後](comparison-phone.png)（左:変更前 / 右:変更後、上:販売室 / 下:貯蔵庫）。個別PNGは390×844と1024×768、それぞれ変更前後・販売室/貯蔵庫を保存。同じ正規操作で作成したセーブ、固定時刻、同条件で比較。

- Chromium 153、390×844と1024×768で描画・操作を確認。時間線を実ラスタで計測し、DPR1で2物理行、DPR3で6物理行＝2 CSSpx。線の上端と年月枠の下端が一致。
- 時間進行・再生停止、販売室/貯蔵庫の切替、担当者画面から停止→再開→取消を確認。描画へ即時反映。完了済み予約の非表示も確認。
- 年月/状態のサイズ20、商品名の視覚的省略、本数と文字の非重複を確認。通常月と12月の折返しも確認。
- 棚・瓶・樽の配置、操作領域、同条件セーブのハッシュ一致。電話/PCの樽4個・瓶2個、計12描画領域は変更前後のピクセル一致。
- node syntax、canvas-layout/hud-controlsの既存6テスト、git diff --check が成功。詳細は browser-results.json / pixel-results.json / browser-review.mjs。
- 表現監査: 新しい説明文・装飾・常設案内なし。既存の操作発見性とアクセシブルラベルを維持。
