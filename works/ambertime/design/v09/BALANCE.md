# 0.9 継続卸売の経営監査

再実行: `node works/ambertime/design/v09/simulate.mjs`

## 条件と情報の制限

初期資金£1,600、12シード（1〜10、42、20261016）、240か月。0.9の3方針と0.8.1の単発契約方針を同じシード・月数で比較する。各ケースは最終保存の完全再現、各月・資金操作後の `初期資金 + 売上 − 費用 − 維持費 = 所持金` を検査する。

全方針とも最初の2仕込みは1樽ずつ6か月で通常販売し、その後は資金の範囲で4樽を目指す。抽出終了80、100msごとに抽出1ステップ、60ステップで共通の1か月。抽出中も月次処理を進め、抽出を同月内で瞬時に完成させない。樽はリフィル／バーボン交互、通常販売価格は「標準」。卸売未指定の樽は仕込み順で18／24か月を交互に目指す。

| 方針 | 卸売への割当 |
| --- | --- |
| retail | 全て通常販売、申し出は断る |
| mixed | 3仕込み目以降の奇数番の樽を、明示操作で指定 |
| wholesale | 3仕込み目以降、指定可能な樽を一つずつ明示指定 |
| v081-single | 0.8.1の現行実装で、再度の申し出が来る都度1樽を契約 |

卸売の熟成条件は提示された条件の中から18／24か月に交互に近いものを選ぶ。同距離なら短い条件。値上がりの予測や内部の将来風味は見ない。継続条件の提案は、奇数回目は承諾・偶数回目は辞退する固定方針で、良い条件だけを選別しない。通常の熟成判断は試飲してから「見守る」を選び、最後の判断なら「あと3か月」を選ぶ。試飲は他に6か月間隔と手動瓶詰め前にも行う。

資金保護判断はモデルが選んだ非契約樽の瓶詰めを優先し、契約樽しか提示されない場合だけ、その一樽を解除して回収する。資金保護は瓶詰め費用の予約を守る停止であり、実際に現金がゼロになったこととは区別する。待ち時間・選択の所要時間を人間のプレイ時間に換算しない。

## 出力の読み方

- `balance-results.csv`: 全48ケースの月別経営状態（11,520行）。`cash` は現金、`profit` は累計売上−累計費用−維持費。
- `balance-results.json`: 各ケースの全結果、12・36・60・120・240か月時点、試飲・判断・契約解除回数、出荷例、モデルのSHA-256。
- `retailAskingValue` / `stockAskingValue` は現在の設定価格×在庫本数。未実現の希望売価であり、売上・利益・回収可能額ではない。未瓶詰めの樽に将来価格を付けない。
- 販売チャネルは実際の月次入金を別々に集計。瓶詰め平均月齢は本数加重。帳面の直近12本だけを集計せず、新しく完成した商品を都度追跡する。

## 結果

48/48ケースが240か月に到達し、最終保存の完全再現、全11,520月の資金計算、売上のチャネル別合計が一致した。失敗・進行不能は0件。結果は全シードを含み、成功例だけを選んでいない。実行時の全ソースハッシュはJSONに記録し、終了後にも一致を確認した。

### 確認したこと

- 継続卸売中心では全シードが最初の1回の承諾だけで関係を維持し、36〜41樽を納品した。単発契約では6〜9樽だった。関係の維持に通常販売を再度必須とせず、卸売納品から条件提案が届いた。
- 継続卸売中心の条件提案は240か月で5〜9回。うち3〜5回を承諾し、残りは辞退した。通常の熟成判断は平均60.92回で通常販売のみの61.58回と同程度。卸売指定中にも52〜61回の熟成判断、107〜124回の自由・節目試飲を実行し、熟成判断の省略で販売作業を減らしていない。
- 全ケースで4樽に到達。継続卸売中心は自動出荷で36〜41回空きを作り、その後も43〜47回の仕込みを行った。平均手動瓶詰め回数は41回から2.58回へ減ったが、卸売への明示指定は平均42.5回必要。人間の作業負担が何分減るかはこの監査からは言えない。
- 代表例（seed 1、卸売中心）：40か月目に24か月熟成47本を£15.80で出荷（売上£742.60、瓶詰め費£141、当日差引£601.60）。取引先を維持したまま42・43か月目にも次の樽を出荷した。この差引は蒸留・樽・過去の維持費を引いた利益ではない。
- 全樽を卸売指定すると、最初の資金保護時に一樽だけ解除・通常販売するケースが12シード中7件あった。他の指定と取引関係は維持でき、その後240か月まで進めた。混合方針では非指定樽で回収でき、卸売解除は0件だった。

### バランスの判断と残る課題

卸売中心は売れ残り0本で、出荷月に確定した金額が入る一方、通常販売のみより平均売価・累計収支が低い。同じ抽出・樽選びを基礎とする今回の方針比較では、通常販売の完全な上位互換にはなっていない。通常販売は高い収支、混合はその中間、卸売中心は販売の手動瓶詰め・価格設定・棚出しを大きく減らす選択となった。未販売在庫や熟成中の樽の残量はケースごとに違うため、最終現金だけを全保有資産の優劣とはしない。

一方、全方針とも長期には現金が増え、240か月では初期の資金判断が薄くなる。これは0.8.1にも見られる経済全体の課題であり、今回の継続ルート導入に合わせて調整していない。卸売中心でも初期の費用予約を満たすために一樽を外す場面があり、全樽を無計画に指定すると資金回収の自由が狭まることは残る。新しい救済・収入商品は追加していない。

この監査は休止・終了操作を繰り返す戦略や全ての蒸留条件の最適化までは扱わない。休止・終了・同月複数出荷などの状態遷移は個別の回帰テストで確認する。

## 評価の限界

この監査は合法操作で継続納品、資金計算、保存再現と相対的な経済結果を確認するもの。プレイヤーの愛着、作業を任せる心地よさ、熟成判断の面白さを確認したものではない。現行0.8.1との比較は販売ルートの違いを測る比較であり、最適経営を証明しない。パラメータは変更しない。
