# AmberTime 0.27.1 — 販売室の表示整理

基準: main `4a01ad27` / PR #637。対象は `?placement=1` の販売表示。通常版の計算・保存・UI、Production、既存Labは変更していない。

## 店舗と詳細

選んだ発売回の実brandIdと、町の酒店の既存relationを照合して配分先を表示する。取扱い前は無効ボタン・理由文ごと除去。別ブランドやスーパーの関係では表示しない。取扱い済みで納品不可なら既存quoteの理由を残す。申し出の確認・承認は既存ボタンを維持する。

「個性と仕込み」は実profileの味名1件と、既存帳面の「元の記録」、存在する場合の「前と比べる」に絞った。バー・類似した説明・採取範囲・樽情報の重複・旧発送方式の説明を除いた。正確な製法・採取範囲・熟成・発売回は既存帳面→元たる・仕込みの記録から確認できる。価格は独立した開閉欄、他店/申し出は詳細の外に置く。架空の情報を補完しない。

## 確定の反応

既存commitPlacementの候補検証→保存成功→game差替えを維持。表示結果は自家販売の増減本数と実納品本数から作る。自家販売へ6本なら「自家販売へ6本回しました。」、実納品なら「町の酒店へ2本届けました。」。確定ボタン直上の単一role=status / aria-live=politeに表示し、240msの有限な背景色変化を加える。仮置きの瓶の240msの動きは維持。

変更なしは「配分は変わっていません。」を中立色で表示し、成功演出なし。毎回確定前に古い結果と動きを消すので失敗時に以前の成功は残らない。close/scroll/resize/hidden/reduced motionでキャンセルし、古い終了通知が新しい動きを消さない同一instance判定を使う。常時アニメーション、新時計、新保存項目、履歴は追加しない。

## 棚

既存Canvasのラベル幅132を使い、名前を実測で最大2行に折り返す。4文字＋省略の固定切断を廃止。長すぎる名前のみ末尾省略し、フル名は小窓で確認可能。本数は利用可能数1件だけ、旧状態欄の重複本数を除いた。同ブランドの複数発売回だけ既存状態行に第N回を表示する。瓶・背景・棚・座標・描画スケジューラは維持。配分方式だけsaleStateへ発売回を渡す。Canvasのソース自体も変更していない。
