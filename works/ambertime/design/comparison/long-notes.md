# 比較・製法帳の長期検証

リポジトリのルートから `node works/ambertime/tests/comparison-simulate.mjs`、または `works/ambertime/` から `node tests/comparison-simulate.mjs` で再実行する。`AMBER_OUT=/absolute/path` で出力先を分離できる。

0.17の公開操作シミュレーションで作成したシード1・1440か月（120年）の実保存を、公式の厳密復元で読み込んで使用する。`AMBER_COMPARISON_SAVE=/absolute/file.json` で同じ保存を指定でき、SHA-256が既存の `design/generations/long-results.json` のシード1と一致することを検査する。標準の一時保存が残っていない場合は、既存の `buildGenerationGame(1440)` を公開操作で再実行する。ゲーム状態の注入は行わない。

120年全体を0.18で新しくプレイした検証ではない。実際に120年進んだ0.17の蒸留所を0.18の製法帳対応保存へ移し、その後で製法の記録・選択、比較閲覧、1か月の通常進行を確認する。世代をまたいで製法帳を保持することや選んだ製法で仕込むことは、別のモデル・ブラウザ検証を参照する。

元の蒸留所は3銘柄・9取扱関係を持ち、4回の引継ぎを経て5代目が活動中。既に短い瓶詰め記録や樽アーカイブから消えた古い手動仕込みを、実際の操作履歴から復元して製法帳に2件記録する。抽出位置、樽種、樽ID、バッチID、樽詰め月、操作インデックスを照合する。由来にない銘柄IDなどのメタデータは補わない。記録と選択の前後で、財産・原酒・樽・販売・評判・取引・世代・いつもの仕込みの状態が完全一致することを確認する。

比較データは最初だけ全履歴から生成する。その後、同じ保存での再表示、製法選択1操作の追加、実際の月次処理1回の追加を、同じ派生キャッシュで更新する。各商品の残在庫と全販売先の本数、全商品の売上とゲーム累計、価格別の自家販売実績、実在の手動仕込みの由来、識別子の重複を検査する。比較を開く前後で元の保存を変更しない。通常月次の結果は製法帳へ移す前の版と一致することも確認する。

同じ表示キャッシュからの更新と新しい全再構成が一致することは、価格変更を含む短期の公開操作保存で別途検査する。120年の全比較再構成を何度も繰り返さず、最後に別のNodeプロセスで製法帳付き保存を厳密復元して、保存文字列と製法帳を照合する。入力はUTF-8として読み取る。

初回の全再生と差分更新の時間は分けて示す。派生キャッシュによって再表示が速くても、初回の読み込みが即時になるとは扱わない。測定は共有実行環境のNodeでの単発実測であり、実機・ブラウザの所要時間や人間の操作時間を保証しない。数値計算や保存検証を緩める変更、古い履歴の切り捨ては行わない。

保存上限の判定は6,016,384 UTF-16コード単位未満。UTF-8バイト数やブラウザのlocalStorage容量とは別である。操作12,000件、銘柄128、発売回512、店舗納品2,048件、製法帳64件などの上限までの実測残量を記録する。120年の一つの製造方針で成功したことは、全方針や無限の継続を保証しない。

## 実測結果

120年の厳密保存を復元し、短い記録とアーカイブから消えていた手動仕込み228件を含む、256件の実在の手動仕込みを確認した。そのうち創業時の樽2（バッチ1・抽出40・バーボン・0か月目）と樽4（バッチ3・抽出65・リフィル・2か月目）を製法帳へ記録・選択できた。どちらも1代目の実際の操作インデックスに結びつき、保存に残らない由来の銘柄IDは追加していない。

比較には256項目（現在の4樽と、瓶詰めした252商品）が現れた。252商品には銘柄の発売回163件と卸売商品89件を含む。自家販売・店舗納品・通常卸売・特別注文の合計10,860本、総売上204,769.81がゲームの累計と完全一致した。全商品の在庫と販売先別本数、価格別自家販売実績も一致した。元の120年方針は標準価格を使っており、複数価格の期間については別の15か月実プレイの3価格期間で、差分更新と全再構成の一致を検査した。

| 処理 | Node実測 |
| --- | ---: |
| 元の120年保存の厳密復元・公式シリアライズ | 69.21秒 |
| 検証済み操作の派生情報から手動仕込みの由来を取得 | 9.89ミリ秒 |
| 初回の全比較データ生成 | 89.55秒 |
| 同じ保存で再表示 | 30.44ミリ秒 |
| 製法選択1操作を追加した比較更新 | 49.13ミリ秒 |
| 実際の1か月進行を追加した比較更新 | 43.76ミリ秒 |
| 既知の操作列へ追加した製法操作等の公式保存検証 | 62.84ミリ秒 |
| 製法帳付き最終保存の独立プロセスでの厳密復元 | 76.23秒 |

初回生成には約90秒を要した。差分更新が短くても、初回読み込みが瞬時になるとは評価していない。キャッシュは同じ保存の同じ操作接頭辞が続く場合の派生情報であり、別の保存や分岐に無条件で流用するものではない。

製法帳への移行・記録・選択では、財産とゲームの進行状態は変わらなかった。次の実月（1441か月目）を進めた結果も、製法帳へ移す前の版を同じ1か月進めた結果と一致した。最後の独立プロセスの復元では保存文字列と製法帳が完全一致した。

最終保存は3銘柄・163発売回・343店舗納品・製法2件、操作3,493件。残りは銘柄125、発売回349、店舗納品1,705、製法62、操作8,507件。保存量は396,409 UTF-16コード単位、425,809 UTF-8バイト、792,818 UTF-16バイト換算。復元の文字数上限との差は5,619,975コード単位であり、ブラウザの保存容量の保証値ではない。
