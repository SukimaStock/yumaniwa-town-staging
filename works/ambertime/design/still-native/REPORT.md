# 蒸留器を元の16×16で描く

基準: c05d80a07dcf847f1a7807573b05ae84eb152f8b（PR553）。原作の行データは前回取得した `design/still-codea/source-reference.json` とユーザーが提示したCodea PixelEditorを参照。

原因は前回導入した `round(n*26/16)`。整数座標でも、元の1セルの幅・高さが1または2に変わり、窓や輪郭が歪んでいた。前回レポートの「同率変換で原作比率を保持」という評価は、セルの不均等化を見落としており不十分だった。

ユーザーの「拡大する必要はない、ミニマルでよい」を採用。途中の2倍案は取り下げ、マージ・公開していない。今回の修正は元の16×16を等倍で描く。各元セルは必ず1×1、原点(10,20)、底面y36。配列・色・右端の銅色陰影を維持。独立した拡大処理や端数丸めを使わない。設備全体60×36の枠と机面はそのままなので、以前より本体が小さくなる。

当初指定された既存の管経路15矩形の位置と色を保ち、小さくした本体へ届くよう、接続部の直線部分だけy11〜20に延長。受け器/液流/蒸気/グラス、机/背景/HUD、ゲーム処理/保存は不変。元の配管位置を固定しているため、原作より首の接続部が長い。

前回はshop-appからのart参照のみ更新し、CanvasSceneの描画用art参照がv0.53のままだった。今回はindex→shop-app→canvas-scene→room-object-artのcache参照をv0.55-still-nativeへ統一。Canvas本体の描画・入力ロジックは変更しない。

[比較画像](comparison.png) は元16×16を等倍で配置した本体／修正前／修正後を、同じ60×36セルの表示枠で並べる。比較画像内の表示倍率は観察用であり、実装の本体は16×16のまま。窓の黄色の十字は元の5セル、縦横3セル幅を保持する。
