# AmberTime 画面・文字・操作表示の整理

基準: main `037bf6a9`（PR #511・#512のフォント／小窓修正を維持）。Stagingのみ。

変更:
- 年月と世代を同じ行へ。金額は右。大きな金額のみ次行に逃がす既存の対応を維持。月バーの見えるラベルを削除、読み上げ名は保持。時間ボタンの表示枠を内側へ縮め、48×45論理pxの操作領域を保持。
- コメントを不透明の小枠へ。下部操作より上に配置。表示・消去の仕組みは不変。
- 帳面は既存絵だけ。担当者は7×7セルの人アイコン。操作名は読み上げ用に保持。
- タル／ビンの選択を控えめに点滅するドットの▼へ。減らす設定では常時表示。3室タブを一枠にまとめ、内部区切りと選択下線を保持。
- 読みやすさを現行フォントの比較画像 number-prefix.png で確認し、表示のみ # から No.へ。ID不変。
- 「低め／ふつう／高め」を同じ行に。価格単位は共通の「1本 £…」へまとめ、各ボタンの値と重複させない。
- 納品は「1本／5本／10本」、共通の「納品数 → 残り／入金」と各ボタンの在庫・金額で判断できる形へ。「今回は断る」は「やめる」、「あとで考える」は「あとで」。取扱店条件は必要な値を残して／区切り。保存済み本文や作者の銘柄名は一律置換しない。
- 背景タップは×と同じ closeModal を使用。内側操作・ドラッグは閉じず、既存の必須判断／親小窓へ戻る処理を維持。
- ポインターで小窓を開いた際の自動フォーカスによる黄色枠は見出しへ初期フォーカスを移して解消。キーボードの黄色いフォーカス表示を維持。「試飲」の通常枠は標準色へ。
- たる詰め直後だけ「ビン詰め」を隠して「見守る」。一時的な小窓フラグだけで実現し保存形式は不変。再選択後は既存の瓶詰め経路を維持。
- 試飲の前回値を細い線からドットの▼へ。ゲージ値・色・長さ・評価式は不変。

検証:
- `node works/ambertime/tests/ui-tidy.mjs`: 390×844 と1280×900の変更箇所のみ成功。上部の収まり、48×45の時間操作領域、ページスクロールなし、担当者開閉、内部タップ保持、背景閉じ、Escape、ポインター時の不要フォーカスなし／キーボード時のフォーカス保持、表示開閉で保存バイト不変、試飲小窓の横はみ出し0。390ではたる詰め→見守る→再選択の瓶詰め経路、前回値のドットマーカー、価格3択同じ行、納品3列の幅を確認。ページエラー0。
- 既存の関連回帰: canvas-layout / scene-input 5件、shop-flow / bottle-storage 33件すべて成功。後者は保存再読込と在庫・入金・納品操作の既存検査。
- 実装担当以外による shop-app の差分レビュー実施。計算・時間・保存・担当者・世代交代のモデル／パラメーターはGit差分なし。
- 表現監査: 重複説明を削り、本数・在庫・入金・条件、操作名、読み上げ名を保持。装飾コピーや新画面は追加しない。

既存Planとの差分:
過去の type-ui / quantity-fit Plan は5サイズの全機能回帰、フォント行列、全画面画像等を記載。今回の新しいPlan Lockはユーザー指定に従い上記の軽量検証へ限定する。ゲートや必須CIは省略しない。
