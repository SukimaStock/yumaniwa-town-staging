# AmberTime M1 R0 — 店舗間の口コミ根拠を抽出する

基点: staging main `a870e0affcea2d124c44622652e50eaf6a827637`（PR #879）。PR #880はDraftのため、本編M0・時計・通知画面へ接続しない。

## 今回実装したもの

- `map-relationship-view.mjs` は本編の `labConnection.town.events` を読み取り、選択した取扱店に非直接の口コミ到達（`arrival`）が本当に起きた場合だけ、直前の店舗との関連を返す。
- `sourceId` を納品（`shipment`）と発売（`release`）までたどり、欠損・循環・月の逆転・別発売回・不一致の伝播経路を拒否する。
- `town` ⇔ `town-liquor`、`super` ⇔ `supermarket`、`bar`、`department` の既存ID対応のみを認識。正式取扱いのない店舗や未表示の相手を線の対象にしない。
- 同一選択店に到達が複数ある場合は最新の根拠を最大1件返す。表示用投影のキャッシュはゲーム状態へ保存しない。
- 店舗が実際に選択可能でも、座標を持つマップピンが両端に存在しない場合は `canDrawLink=false`。抽象地域、架空の位置、契約の原因、人間関係は推測しない。

## この段階の限界

まだ表示用モジュールのR0であり、**M1-Aの画面比較LabやM1-Bの本編UIは未実装**。ゲーム内の店舗選択で線は出ない。

現在のM0にはバーの仮位置がある。今後線表示を実装する際は、その位置を正式な建物位置と誤認しない。マップの「観察対象」と「正式取扱店」の区別、店舗未契約での口コミ確認は別設計とする。

町の来歴は本編の実納品から届くイベントを使用する。旧保存に存在しないイベントを作ったり、事件や契約の原因を補ったりしない。
