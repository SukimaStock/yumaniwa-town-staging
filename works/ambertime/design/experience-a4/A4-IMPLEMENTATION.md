# A4 実装・検証

[A4監査](A4-SAVE-AUDIT.md) · [A4表示ルール](A4-SAVE-UI-RULES.md)

- `shop-app.mjs` の既存保存モーダルに保存状態、JSON書き出し、旧方式、維持費、初期化を順に配置。販売方式の切替が可能な場合は折りたたみの外に置く。通常と試遊の初期化確認を分けた。
- `index.html` の旧リンクは維持し、起動時の引き継ぎをコピーと説明。appのキャッシュ参照を `save=a4-1` に更新した。
- 表示専用テストを追加。歴史的なL1ソース照合は今回の既知の差分だけを戻して検証し、保存fixtureは編集していない。
- 独立レビューに基づき、折りたたみの目印、既存の販売方式説明、現在のブラウザ保存を上書きする確認文を採用。
- 正式キー、包みの版、保存・復元・配分・初期化の実行処理、Canvas、Labは保護対象。保存スロット、ファイル読込、バックアップ方式は今回の範囲外。
