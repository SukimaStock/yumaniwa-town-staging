# A4 保存画面のルール

1. 「保存」の入口で自動保存先を「このブラウザ」と明記する。表示を開くことは保存の成功通知にしない。
2. 試遊、保存不可、未保存、保存済みの順で状態を判定する。復元済みまたは読戻しを確認した保存に「保存済み」を使う。保存エラーの詳細と再確認・再読込は既存の案内へつなぐ。
3. 「記録を書き出す」は現在の進行をJSONファイルに残す。ファイルの読込機能の有無を明記する。
4. 旧方式の書き出し、方式の説明、旧版と研究資料は折りたたむ。現在選べる販売ルールの切替は開いた画面から操作できるようにする。
5. 起動時の引き継ぎはこのブラウザへのコピーと説明する。旧記録の保持と正式保存の上書き拒否を維持する。
6. 「新しい蒸留所で始める」は書き出しから離す。確認文には現在のブラウザ保存が上書きされることと、先に書き出せることを示す。試遊は試遊のやり直しと表示する。
