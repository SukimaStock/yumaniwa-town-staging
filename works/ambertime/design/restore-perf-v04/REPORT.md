## Current limited optimization

All actual data uses native structuredClone, preserving complete detachment and aliases. WeakMap stores only quantization prefix lengths in private synchronous formal-validation replay, for three append-only logs events/arrivals/attempts. New records are still visited; only proven rounding fixed points can extend prefix. No state or persisted metadata is shared, no history is removed, no replay operation or reader check skipped. Public operations get no prefix trust. Mutation of old numeric log fields in future code invalidates the optimization assumption and requires review.

Public compatibility was corrected in 7e466f5e: row-wise traversal is private-replay-only; public traversal remains the original visit(array), including sparse arrays and enumerable extra properties. Independent review confirms private-replay calculations unchanged. The 9fa five-strategy results can be reused as bounded differential evidence, not described as a full rerun on7e.
