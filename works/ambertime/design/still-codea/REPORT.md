# AmberTime 蒸留器の原作再現

基準: `3cee363a45a25c030a21ee3e1e5bd2eb10b29fda`（PR #552後）。前回修正前は `55b2d09bfc9a571def5316feceeb756a6d076699`（PR #551）。変更は蒸留器と配信cache参照だけ。Productionは対象外。

## 原典と解釈

[Drive AmberTime.txt](https://drive.google.com/file/d/1cAtwEtLj0DoMbrw7XOwI0XdcA2dopTFi/view) の `DistilleryAssets.PotStill`（14344–14363行）が16×16の正本。`DistilleryScene:drawStill`（8989行以降）は炉下のランダム色矩形→スプライト→横管→縦管の順。`DotMatrix:drawSprite`（9658行以降）は上からの行をY反転し1セルずつ描画、`noSmooth()`で表示する。`GameRenderer:setupPalette`（5196行以降）の上書きも照合した。関連するコード抜粋を [source-reference.json](source-reference.json) に保存した。

- 原作コードに存在: 銅184/115/51、青41/173/255、明るい黄255/255/100、褐色60/40/30、石90/90/100、赤褐色171/82/54。太い黒枠、黒い外側の影、独立した脚はない。
- 原作の青/黄の十字はコメントでは Highlight、右の2×2褐色部は名称なし。画像 `IMG_6156(3).png` の十字部分を窓として読めることを確認した。「窓」という名称は画像からの解釈。
- 下3行は Furnace Base / Fire Glow。左右の褐色セルを薪の端として読み取った。コードに「薪」という名称や丸太の細部はないため、独自の薪模様・炎は加えていない。
- 原作16×16の全行の形・配色位置を整理した後、Webの既存足元y36に合わせ、x=6+round(column×26/16)、y=10+round(row×26/16)へ変換。整数境界を共有し、元の縦横比を保つ。単に以前のWeb本体を縁取りなしにした形ではない。

## 残す部分と描き直す部分

前回修正前の銅色の管と受け器は残す。PR #552の本体の黒枠・右側の大きな影・独立した黒脚・黒い四角だけの窓は取り除く。本体のシルエット、青い首元、十字の窓、小さい褐色部、石の炉と左右の薪の端を原典から描き直す。接続部のキャップだけは原作の金属色から銅色にし、既存管との接続に1行重ねる。右端の銅セルにのみ暖色の暗色を使い、黒い影を作らず立体感を補う。

## 実際の描画比較

[比較画像](comparison.png) は原作画像の切り抜き／PR #552前／PR #552後／今回の4列。共通の背景色、設備全体の表示高さと足元を合わせ、nearest-neighborで拡大した。Web3列は60×36セルを同じ4倍表示。原作は別の管経路なので、本体だけの高さまで同一ではない。原作画像の背景は切り抜き内に残している。ソースを読んだだけの比較ではなく、この画像とPC/縦画面の実描画を目視した。

| 項目 | 結果 |
|---|---|
| 原作のシルエット | 改善。16行の輪郭を同率変換し、太い黒縁で太っていた胴を復元 |
| 太い黒枠 | 改善。本体には黒系19141eを使わない |
| 管とのつながり | 改善。根元を銅色で連続させ、既存経路と15矩形の座標・色は維持 |
| 窓 | 改善。原作の青い縁と黄色の十字を復元。右の小さい褐色部も原典に従う |
| 薪・足元 | 改善。左右の褐色セルと中央の赤褐色を石色の炉内に復元。黒脚を撤去、炉の底は机面y36に接する |
| 不自然な影・段差 | 改善。大きな右黒影を撤去。段差は原作の輪郭を一定倍率で整数化したもの |
| 前回修正前との明瞭さ | 改善。点のような金具から十字の窓へ、2本の脚から炉の構造へ判別できる |

残る差異: Web管と受け器は元のまま。原作の金属キャップを銅へ変更。銅の右端に暗色を補った。16→26セルの整数化で元の各セルは1または2セル幅になる。原作のランダム炉下点滅は移植せず、既存のWeb蒸気・液流だけを維持。原作の画面構成や家具は移植していない。

## 限定した検証

- 描画関連16件成功。管15矩形の出力hash、受け器・蒸気・液流・グラスのhash一致、整数座標・寸法・配置を確認。
- 390×844 touch、1024×768 PC、それぞれ待機中・蒸留中の変更前後8画像を保存。同一の合法な保存、seed42、固定時刻を使った蒸留中2組は、hitRegions・家具位置・HUD/文字計測・保存内容・フォントが完全一致。ページエラー0。
- メニュー開閉・時間切替後の保存不変、初期状態からの蒸留開始でphaseがdistillingになることを確認。初期化はテスト用ブラウザに限定。
