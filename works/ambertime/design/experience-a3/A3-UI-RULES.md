# A3 数量表示の共通ルール

- 現在値は符号なしで単位を明示する。差分は `+` または `−` と絶対値を空白なしで並べる。対象欄に「本」があれば差分側では省略し、対象が曖昧なら単位を添える。ドット絵の描画先では表示できる字形を確認する。
- 差分は既存の数字フォントと金色を使い、増減は符号で伝える。発売回と店舗ごとの数値に結びつけ、日付・ボタン・他商品の欄に重ねない。売却の固定枠はその場に留める。
- 500〜700msの範囲では、500msは現行の読める時間を短くし、700msは連続操作で前の結果が残りやすい。既存の650msを採用する。前半65%は不透明、後半35%で消す。棚外の差分は上に3pxずつ最大6px。固定枠と旧配分は位置を維持する。完了時は要素を削除する。
- 物の移動は瓶で表す。既存の配置と売却の方向・時間・表示上限を引き継ぐ。正式操作の成功後に現在値と演出を更新し、演出の完了から在庫や現金を更新しない。
- 旧配分の仮操作は表示上の数が変わった場合だけ反応する。ゼロ、失敗、再描画、再読込、重複イベントでは出さない。連続操作・画面遷移では既存の取消処理で前の表示を消す。
- ステッパーは左に減少、中央に選択値、右に増加。左右45px、間隔8px、高さ48pxを目安にする。範囲外は無効化。「残り全部」と選択式の役割を保つ。値を選ぶだけで確定処理を実行しない。
- reduced-motion は移動・浮遊・フェードを省略する。現在値を即時更新し、必要な静的差分や読み上げ用statusを維持する。装飾差分は aria-hidden とし、同じ操作の可視トーストを追加しない。
- 受入時は狭い画面で重なりとタップ先、連続操作・閉じる操作で残像、保存失敗と復元で無演出、月次で通知の過剰発生がないことを確認する。
