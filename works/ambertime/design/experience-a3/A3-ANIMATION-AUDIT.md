# A3 数量表示の監査

基準は main `00db30c2`（A2追加修正 #786）。分類は A 現在値、B 一時差分、C 物の移動、D 出来事の通知。設定中の選択値には S を用いる。

| 画面・表示 | 分類 | 現行の挙動と判断 |
| --- | --- | --- |
| 蒸留の原酒量・蒸留結果 | A | `spirit-readout-view` と結果画面の L 表示。採取・結果それぞれの量を表示 |
| グラスの液面 | A/C | `canvas-scene` の採取進度に応じた上昇。A1の完了時の光は採取完了の手応えとして維持 |
| 原酒から樽への移行 | A/D | 樽選択画面の量と詰めた結果。追加の符号や移動演出は省く |
| 熟成・樽残量 | A/D | 現在の L と熟成・比較文。蒸発に毎月の浮遊を加えない |
| 手動瓶詰め | A/S/D | 樽残量と可能本数、選択値、完了本数・残量を分離。ステッパー寸法を統一 |
| 担当者 | S/D | 共通設定の選択本数、予約状態、完了本数。完了集計と個別完了の差引は既存通知に任せる |
| 手元・店頭の瓶 | A | 発売日と本数。売れた後も店頭の欄は実残数。地図の売／残と帳面の記録は用途別に保持 |
| 配置 | A/B/C/D | 保存後の在庫と ±n。販売室の数値は650ms、配置の瓶は300ms、枠は160ms。読み上げ用statusを使用 |
| 引き取り | A/D | 確認後に店頭の行を外し手元を更新。読み上げ用案内。消えた店頭行に差分を置く設計は保留 |
| 自家販売・町の店の売却 | A/B/C/D | 発売回別の残数と固定枠の −n、650ms。瓶は店側へ。別枠の販売結果保持は1300ms。瓶1群210ms、全群の開始差は最大390ms。表示上限と時差は既存方式を維持 |
| 旧配分 | S/B/C/D | 仮の配分・残量、650msの差分、瓶210ms・枠160ms。確定の案内と仮配置は別。ハイフンの減少符号とフェードを揃える |
| 資金・売上・入金 | A/D | HUDの £、月次の売上と入金、帳面と個別納品の履歴。既存の集約を活用 |
| 瓶詰め費・採用費・給与・維持費 | A/D | 見積・支払い条件・月次結果・累計に分けて表示。支払いごとの浮遊を追加しない |
| その他の入出金 | A/D | 卸・特別注文・発送等は既存の条件表示、履歴、イベント集約で扱う |

参照先は `shop-app.mjs`、`market-ui.mjs`、`placement-ui.mjs`、`retail-sale-motion.mjs`、`room-motion.mjs`、`event-notices.mjs`、`canvas-scene.mjs`。既存の[数量位置の記録](../count-linked-delta/)と[店舗の売却演出](../all-shop-flights/)を引き継ぐ。
