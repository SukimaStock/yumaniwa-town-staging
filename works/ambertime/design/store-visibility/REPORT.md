# AmberTime 0.17.1 — 取扱店の表示導線

ボトル詳細の販売先を、その発売回の銘柄と取扱関係のある店だけにした。初めは自家販売だけが見える。空の店舗一覧や未契約店の説明は追加しない。

## 既存状態と表示

| 既存の状態 | 表示・操作 |
| --- | --- |
| この銘柄に取扱関係なし | ボトル詳細には自家販売のみ |
| 未承諾の申し出 | 既存の申し出モーダルで紹介。後回しなら販売室の店舗からの申し出ボタンで再確認 |
| 取扱い承諾済み | 対象銘柄の各発売回に店舗を表示 |
| 承諾済みでも熟成・風味・在庫等が条件不足 | 店名と既存の納品不可理由を表示 |
| デパートの相談を承諾済み | 有効な限定企画に対する既存の納品操作。条件未達ならその理由 |
| デパートの企画完了 | 追加納品ボタンなし。完了状態・過去の採用と銘柄の来歴は維持 |
| 辞退・取扱関係なし | ボトル詳細では非表示 |

表示判定には、発売回の `brandId` を渡す既存の `shopBrandStats` を使う。別銘柄の店を借用しない。同じ銘柄の再発売では関係を維持し、実際の納品可否は対象 `productId` の在庫・熟成・風味を既存の `shopQuote` で判定する。デパートを表示するだけで自由納品にはならない。

申し出の保持・通知済み状態・保留・承諾・辞退・複数申し出の順序は既存処理のまま。デパートの相談を承諾すると、既存処理が銘柄×店舗の関係と限定企画への関心を作るため、承諾後の納品待ちは表示される。旧版から継承したデパート関係にも同じ判定を用いる。

## 保護範囲

本編の変更は `shop-app.mjs` の店舗描画と、`index.html` の版表記・アプリ読込クエリだけ。保存はv16・同じキー・同じ操作履歴。新しい状態・保存項目・移行処理・数値計算を追加しない。

世代交代の条件、最後の仕込み、先代の樽と発売履歴、歩み、蒸留・熟成、4樽、保管／自家販売、いつもの仕込み、卸売／特別注文、取扱条件・価格・評判は変更しない。世代をまたぐ関係は既存の保存済み関係をそのまま表示する。Production・共有コード・作品台帳・LABの入口は変更しない。

表現監査6点を確認。未契約店舗の先取り表示とその説明を削り、新しい説明文・管理画面・装飾は追加していない。自家販売と既存の申し出・承諾・納品操作の発見性は検証対象に含める。
