# 身近な比較の読み取り性能

`node works/ambertime/tests/nearby-simulate.mjs`。既存120年保存がない場合は同じ公開操作方針で再生成する。`AMBER_NEARBY_SAVE`で既存のseed1・1440か月保存を指定できる（既存検証ハッシュと照合）。

共有マシン上のNode読み取り処理時間。ブラウザ描画時間・実機iPhoneの操作時間ではない。コールド保存検証は比較表示の時間と分けた。

| 処理（ms） | 一代分（312か月） | 120年（1440か月） |
| --- | ---: | ---: |
| strictColdRestoreIncludingReceipts | 6688.5 | 79968.49 |
| initialCasks | 12.65 | 43.08 |
| changeCaskPartner | 5.67 | 19.67 |
| reopenCasks | 5.39 | 20.59 |
| initialReleasePair | 5.68 | 22.09 |
| changeReleasePair | 5.51 | 20.66 |
| reopenReleasePair | 5.25 | 19.38 |
| oldFullProjection | 7370.97 | 83590.73 |

各対象について従来の全履歴投影と、抽出・樽・風味・在庫・自家販売本数・実売価格・実際の販売期間・店舗納品を照合。同じ銘柄の直前発売であること、読み取り前後のゲーム状態・製法・世代記録の一致、通常の短期記録から外れた仕込みへの参照を確認した。

初回の厳密な保存検証では操作履歴を再実行し、その同じ検証中に一時的な実績コンテキストを作る。検証後の樽比較・発売回比較はその対象だけを読み、全履歴を再構成しない。保存形式・判定の厳密さは維持している。

一つの製造方針・seedの観測結果。全戦略の保証や実機Safariの確認ではない。
