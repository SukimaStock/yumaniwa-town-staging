# グラス象徴色の監査

基準は main `6c8b2be96c81646bab59ae69964342b5a46e6d94`。本編の `attachFlavor` で実際に使う48点平均を読み取り、開始0–87・終了開始+12–99の3,916カットを、普通／ピート麦芽×短い／長い発酵の4条件で計算した。計15,664件。正式モデル、採取幅、収量、価格、保存を変更していない。

## 比較・採用

[同条件のA/B/C比較](audit/glass-comparison.png)では、A＝従来バーと同じ二乗重みの連続混色、B＝代表色、C＝代表色に3段階の濃淡を追加した。どの案も同一の既存profileを入力し、液面の高さは同じにした。

**Bを採用する。** Aは異なる個性が似た中間色になりやすい。Bは小さな液体面でも果実・麦・煙・厚みを見分けやすい。Cは同系統の差を多少残せるが、暗さが強さや良し悪しの順位に見える可能性があり、小面積では追加情報が弱い。色は品質・価格・実際の透明な蒸留液の色を示さない。

代表色は既存バーの4色を継承する。果実 `#c58fa4`、麦 `#c3ad6b`、煙 `#8494b2`、厚み `#6ca6a0`。僅差の混合のみ中立色 `#a3a39c`。

採取中の暫定色は採用しない。最小12step未満を含め、未確定時は従来の中立色を保つ。正式終了で既存profileが確定した後だけ色を切り替える。これにより、操作中の色を追いかけるゲージや、境界付近の色のちらつきを作らない。象徴液面・高さ・保存とは独立している。

## 分類方法

単純な最多成分は既存の味名と4,179件（26.68%）で食い違った。味名は元々、果実×1.05、麦×0.92、煙×1.18、厚み×0.89で個性を決めるためである。表示にもこの**既存の個性判定の重み**を使う。新しい味計算ではない。

上位2成分の相対差 `1 - second / first` が5%未満の場合だけ混合色とする。10%近辺まで拡張すると混合が増え、特にピート短発酵で独自の煙の個性を隠すため、狭い5%を採用した。成分ごとの最大値で正規化する案も比較したが、既存の煙の特徴付けを別基準へ変えてしまうため採用しない。均等な件数へ調整していない。

| 仕込み | 果実 | 麦 | 煙 | 厚み | 混合 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 普通・短発酵 | 377 | 2495 | 0 | 668 | 376 |
| 普通・長発酵 | 2481 | 0 | 0 | 1273 | 162 |
| ピート・短発酵 | 0 | 0 | 2890 | 368 | 658 |
| ピート・長発酵 | 953 | 0 | 1920 | 368 | 675 |
| 合計 | 3811 | 2495 | 4810 | 2677 | 1871 |

混合は11.94%。何でも入る残余分類ではなく、必ず既存の上位2成分の僅差である。非混合13,793件は既存の味名の個性と全件一致した。ピート短発酵で麦の色がないことは、既存の味名でも麦優勢が24件しかなく、その24件が僅差内にあるためである。表示分類でそれを人工的に増やしていない。

開始・終了を片方だけ1step動かす合法な隣接関係30,624組のうち、色系統が変わるのは688組（2.25%）。それ以外は同色を維持する。近接するprofileが代表色の境界で切り替わること自体は残る。切替は正式終了時の一度だけであり、演出中には揺れない。

[全カット分布](audit/classification-map.png)、[全15,664件CSV](audit/profiles.csv)、[集計JSON](audit/summary.json)で追跡できる。CSVのprofileは9桁表示、分類計算には元の12桁profileを使用する。

## 限界と誤解を避ける扱い

代表色は4成分全体の距離を表す計器ではない。同色内でも4次元profileの最大距離が0.98になる組があり、同じ煙色でも果実や麦などの副成分は異なる。混合色も、異なる2成分の組合せを同じ中立色にする。**同じ色なら同じ味とは扱わない。** 既存の味名・香り・刺激・結果表示を維持し、色を個性を覚えるための手掛かりに限定する。

発酵・麦芽を変えると同じカットでも分類が変わる例がある。比較画像の12–36は普通短／長で果実、ピート短で煙、ピート長で果実になる。位置による色割当ではない。採取中のバーの連続混色とは役割が違い、グラスは確定した代表的な個性だけを残す。

## 再現・検証

```sh
node works/ambertime/design/cut-pixel/audit/run.mjs
node --test works/ambertime/tests/flavor-color.test.mjs
```

テストは全15,664件で既存の個性判定との一致、連続混色との一致、決定性、入力非変更を確認する。任意の4系統・空のprofile・欠損profileも検査する。集計の全件数と5%混合条件も確認する。比較PNGは同梱SVGをChromiumで等倍に描画した資料画像であり、実機iPhone Safariの検証ではない。画面内の小さなグラスでの確認は、本編の画面幅別ブラウザー検証資料を参照する。
