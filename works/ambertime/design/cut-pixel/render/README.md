# カット色・描画比較

同じ通常麦芽・長発酵・21–74stepを、同じ240×6pxバー、同じ採取印、同じグラス形状・液面で比較した。`comparison-{360,375,390}.png` はその幅でのCSSピクセル画像。画面全体の操作検証とは別の、描画関数を直接使用する静止比較資料である。

| バー | 比較結果 |
| --- | --- |
| 旧：連続混色 | 3px列ごとに異なる近似色。変化が滑らかで、列の境界が認識しにくい |
| A：縦列 | 既存混色をRGB16刻みへ表示量子化。同じ条件で9色となり、3px列と色の段階が見える。採取印を最も読み取りやすい。採用 |
| B：軽いディザ | 3pxセルの固定2行パターン。ちらつきはないが、6pxの細いバーでは区間の小印と競合する |
| C：主・副成分模様 | 成分の違いは強く出るが、細いバーが模様として目立ち、現在位置より先に視線を引く |

Aの色の切り替わりは連続profileを表示量子化した結果であり、固定的な初留・中留・後留の境界ではない。入力profile・正式な味計算は量子化しない。現在位置、採取開始・終了、暗化、下線・小印は全方式で同じ矩形を最後に描く。

グラスは同じ確定profileについて連続混色・代表色・代表色＋濃淡を比較する。代表色は連続混色より小さい液面で違いを見分けやすい。濃淡は、この寸法では代表色に対して利益が小さい。下段は4仕込み条件×3カットの正式な既存 `distill` profileを使用し、代表色がカット位置固定ではなく条件にも応じることを確認する。分類件数・境界・名称対応は別の監査資料を参照。

`drawDistillTools` の色入力は任意の `liquidColor` / `liquidHighlight` のみ。省略時の中立色、液面高、グラスの輪郭、レバー、誘導、操作は変更しない。確定前に色を渡さない責任は本編のホストにあり、採取中の中立表示を維持する。

再生成：repository rootで `node works/ambertime/design/cut-pixel/render/capture.mjs`。比較HTMLは資料用で、本編の操作・モデル・保存へ接続しない。Chromiumの静止画比較であり、実機iPhone Safariの色差や触感を検証したものではない。
