# AmberTime 0.23.2 — 商店の人の一言

## 範囲と結論

基準は着手時の main `55c23c3c88343fbb3b3bd82f5801aa378fb83637`（PR #549）。既存の店舗詳細画面に、実際の取引記録から選ぶ一言を追加した。人物・会話モーダル・ボタン・保存項目・評判点数は追加していない。商店間の紹介は引き続き保留。

`shop-remarks.mjs` は取引事実の抽出、店舗別の状態判定、文言テーブルを分離した純粋な表示ヘルパー。店舗とブランドを絞り、現在月以前の正の実納品だけを集計する。同じ月の複数納品は1納品月。納品のない月は増えない。販売在庫・店頭在庫を推測せず、消費者への売り切れも断定しない。

## 一言と判定

判定は上から優先。閾値は文言を選ぶためだけに使用し、取扱い・需要・解放条件には接続しない。

| 店舗 | 状態 | 一言 |
|---|---|---|
| 酒店 | 実納品なし | いらっしゃいませ。 |
| 酒店 | 最終納品から6か月以上 | しばらく届いていませんね。 |
| 酒店 | 実納品月が6以上 | 何度も届けてくれましたね。 |
| 酒店 | 実納品月が2以上 | 少しずつ届けてもらいましたね。 |
| 酒店 | 実納品月が1 | ウイスキー、届きました。 |
| スーパー | 実納品なし・取扱開始前 | いらっしゃいませ。 |
| スーパー | 実納品なし・取扱開始後 | 取扱いを始めました。 |
| スーパー | 最終納品から6か月以上 | しばらく届いていませんね。 |
| スーパー | 実納品月が2以上 | 何度か届けてもらいましたね。 |
| スーパー | 実納品月が1 | ウイスキーを受け取りました。 |
| デパート | 承認済み5本の納品待ち | 5本、お待ちしています。 |
| デパート | 現在の申し出・未承認の関心あり、過去の5本取扱いあり | こちらの発売回も、気になります。 |
| デパート | 現在の申し出・未承認の関心あり、過去の5本取扱いなし | この発売回が気になっています。 |
| デパート | 実際の限定5本取扱いあり | 5本、受け取りました。 |
| デパート | それ以外 | いらっしゃいませ。 |

デパートは承認待ちの商品を受取済みと言わない。過去の取扱いがあっても、新たな申し出があるときは対象発売回への関心を優先する。欠けた履歴では受取・継続取引を創作しない。

## 表示と表現監査

既存の個別店舗画面内に引用符つきの段落を1つ配置した。通知や自動ポップアップは追加しない。店舗を自分で開いたときの既存モーダルの時間停止は従来どおりで、一言による新しい時間停止はない。閉じた後の月次処理にも一言を通知しない。

- 必要な状態や承認ボタンを残し、説明を台詞に丸ごと移していない。
- 人名・立ち絵・親密度・称賛・新しい常設パネルを追加しない。
- 既存フォント・文字サイズ・余白・ボタン・画面構造を維持する。
- 店舗別の一言は5種類ずつ。同じ条件なら同じ文言を返す。
- 保存や計算へ書き込まないため、表示回数や再訪問で実績が変わらない。
- 需要・価格・資金・給与・取扱条件・自動発送・限定5本・通知処理・モデル本体は変更しない。

## 検証

単体テスト8件成功。凍結入力、店舗・ブランド分離、正の実納品・異なる納品月・最終納品、経過月や一括大量納品だけでは継続にしないこと、在庫非参照、デパートの承認前後と再申し出、実際の5本だけの受取判定、新規ゲームの合法な取引と別プロセス保存復元、表示前後の会計不変を確認した。合成履歴による境界テストと、公開モデル操作による実ゲーム検証を区別している。

```sh
node --test works/ambertime/tests/shop-remarks.test.mjs
node works/ambertime/tests/shop-remarks-browser.mjs
```

ブラウザ検証は16場面成功し、全表示が1〜2行に収まった。表示前後の保存・会計・履歴は一致。既存の店舗モーダルを閉じると通常の月次処理が再開し、台詞による新しい通知・ポップアップは発生しなかった。デパートの承認済み5本は翌月の実納品・入金とも一致した。ブラウザ検証の条件と結果は [browser-results.json](browser-results.json) を参照。390×844の縦画面で既存操作、改行数、保存復元、通常の時間進行を対象に限定した。

## 未検証事項

スーパーの複数納品月の台詞は有限の実取引ブラウザ分岐では未到達（需要と共有在庫の結果、実発送は1納品月のみ）。判定の境界は単体テストで確認した。実機iPhone Safari、VoiceOver、作者による言い回し・操作感の最終採用は未確認。包括的E2E・長時間の手動プレイ・無関係な画面の再検証は実施していない。Productionと既存のユーザー保存データは変更しない。
