# 調整C — 仕込みカード

基準main: `0935d8de0f544b32c8ed1e78cfe9823c98f4a045`（PR #597）。Stagingのみ。

## 範囲と終了条件

既存4枚の見た目・手動選択・初回手動樽詰めによる長い発酵の解放に限定する。小さな絵で麦芽と発酵を選び、既存の蒸留を始められれば終了。新カード、アニメーション、風味・蒸留・熟成・街・販売の再設計、Productionは対象外。AGENTS / Change OS / 表現監査を適用し、実装前r0を固定した。既存PR #588〜#590、#592〜#597の接続を維持する。

## 4種類の絵と表示

`brewing-cards.mjs`の16行×16列が正本。Canvasの整数座標へ1ピクセルずつ描画する。ぼかし・グラデーション・画像縮小を使わない。ゲーム中は既存のピクセル表現に合わせ3倍の48 CSS pxで表示する。

- ふつうの麦芽：一本の金色の穂。2色。
- ピート麦芽：同じ穂の配置を茶色2色へ変更し、灰色の煙2ピクセル。
- 短い発酵：液面の線と明るい泡。3色。
- 長い発酵：同じ液面の配置、濃い琥珀色、少ない泡。3色。容器なし。

`adjust-c-icons.png`は同じピクセル配列を最近傍10倍で並べた比較画像。ゲーム用画像を別途管理しない。

変更前は文字ボタンが並び、長い発酵も初めから選択できた。変更後は麦芽2枚、発酵2枚をそれぞれ横並びにし、カード全体をタップ対象とする。選択状態は既存たる選択と同じ枠色・背景。未解放は暗い背景と小さな鍵、disabled状態と解放条件のアクセシブル名を持つ。名前は7文字以内、説明文は付けない。拡大文字では既存モーダルのスクロールを維持する。

## 解放と互換性

既存の`staffExperience.manualFills`または現在・`origin`の操作履歴の`fill`から解放を導く。成功した手動樽詰めのみが対象で、`complete-usual`、蒸留開始・終了、単に樽が存在することは新しい達成とみなさない。過去の手動樽詰めは瓶詰めや世代交代後も履歴に残る。

保存キー、バージョン、スキーマ、操作種類は変更しない。新しい解放フラグも追加しない。旧製法・担当者・実行中の蒸留・旧readerを変更しない。

既存モデルはカード初期値がlongのため、未解放の手動UIではshortを選択状態にし、カード選択または開始の明示操作時に既存`flavor-cards`操作で記録する。モーダルを開く／閉じるだけでは旧保存を書き換えない。既存のlong製法・担当者の再現にはこのUI制限を適用しない。解放後は次の仕込み画面でlongが通常の選択肢になる。専用通知・演出は追加しない。

## 関連検証

新規5テスト：16×16の描画、3種類の初期選択とlong拒否、表示と計算のshort一致、手動樽詰め後の解放・保存往復、実在する旧保存3件、既存4組み合わせのLab計算との一致。既存調整Bの5テストを追加し、旧履歴のハッシュ、旧・新製法保存、担当者1回・3回再現、再読込を確認する。モデル・数量・費用・口コミのソースは無変更。

独立した読取監査により、初期longの扱い、手動fillと自動complete-usualの区別、旧originの扱いを事前確認した。表現監査：グループ名・カード名・必要な解放条件だけを残し、説明カードや雰囲気のコピーを追加しない。

公開版の表示・操作と配信一致はPRの公開確認コメントに記録する。iPhone/Safari実機の触感、作者による見た目の採否・面白さは未確認。全機能テストや大規模シミュレーションは実施しない。
