# AmberTime 0.16.1 — デパート取扱いの比較監査

推奨する設計方向は **C：企画別取扱い**。同じ製造内容でも、企画によって選ばれる抽出時期が変わった。次の最小実装は、Bの「一企画5本で完了」と銘柄の来歴を一企画で試す範囲とする。Cの複数企画は今回は本編に導入しない。

今回の比較で最も多く納品できたのはAだった。Cを推す理由は販売量ではなく、選ばれる理由を風味と発売回に結び付けられることにある。「育ててよかった」と感じられるかは試遊で確認する必要がある。

## 調査対象と再実行

基準はStaging `368120c12761c965e6967a5e560ab438f5d91f5e`。関連実装は[PR #456](https://github.com/SukimaStock/yumaniwa-town-staging/pull/456)。`shop-model.mjs`、`partner-orders.mjs`、`shop-app.mjs`、`brand-reputation.mjs`、発売履歴・熟成計算、既存の `design/stockists/` と `tests/stockists-simulate.mjs` を調べた。本編・保存・Productionは変更していない。

リポジトリのルートから、Node.js 24で次を実行する。追加パッケージは不要。

```sh
node works/ambertime/design/department-audit/simulate.mjs
node works/ambertime/design/department-audit/analyze.mjs
node works/ambertime/design/department-audit/boundary-check.mjs
node --test works/ambertime/tests/stockists.test.mjs
```

`simulate.mjs` はOSの一時ディレクトリに本編モジュールをコピーし、B/Cの取扱処理だけを変更する。本編の入口から比較モデルを読み込まない。化学・熟成・需要・評判・費用は同一。Aは申し出観測用の非変更フックだけを加える。本編直下の全49個のmjsについて実行前後のハッシュを照合し、一時コピーでも他モジュールが元と同じであることを検査する。

`results.json` と `summary.csv` が走行結果、`diagnostics.json` が分母付きの集計。`offers.csv`、`deliveries*.csv`、`releases*.csv`、`funnel*.csv`、`capacity.csv`、`competition.csv`、`failures.csv`、`months*.csv`、`calibration.csv` に観測を残した。大きいCSVは同じヘッダーで分割する。集計の再生成は `analyze.mjs` だけでも行える。

## 現行の取引処理

デパートの申し出は、自家販売40本・売れた発売回2回・銘柄作成後2か月・正の評判補正に加え、24か月以上・刺激0.30以下の販売中在庫を要求する。**申し出に必要な在庫は1本以上で、5本以上ではない**。納品には同じ発売回から5本必要で、複数発売回の端数は合算できない。

月次処理は自家販売を先に行い、その後、安全な状態で申し出を判定する。蒸留中・樽の判断・卸売の申し出などで判定できず、店舗共通の新規申し出待機も6か月ある。待機列は申し出を保持する。辞退は店舗・銘柄ごと12か月の再検討待ちとなる。

現行Aは銘柄と店の継続関係であり、同じ銘柄へ再び申し出を出さない。承諾だけでは納品しない。納品は共有在庫を減らして入金を一度だけ計上し、自家販売実績と評判から除外する。履歴には店舗・銘柄・発売回・年月・本数・単価・金額があるが、企画IDや選考理由はない。完売商品が棚から除かれても、発売回の熟成・風味・樽・抽出位置は残る。

## 1.35%の内訳

既存と同じ8シード・120か月・製造方針を再実行し、各シードの現金・期末在庫・3店の納品数がすべて既存結果と一致した。酒店1,457本、スーパー2,920本、デパート60本。**60÷4,437＝1.352%は店舗への納品だけの比率**で、自家販売7,207本を含む全販売の比率ではない。

この方針は抽出65・バーボン樽・単一銘柄。36か月目まで2樽で6か月品を作り、その後4樽で6・12・24か月を割り振る。納品は48か月目から、瓶詰め後に一度月を進め、デパート→スーパー→酒店の順に行う。最初のデパート関係ができるまでは24か月品を自家販売に残す。関係成立後は、デパートに5本渡した直後、残りを他店へ渡す。この在庫配分も結果に含まれる。

| 確認項目 | 元の120か月・8シードの実測 |
| --- | --- |
| 1. 24か月以上の商品割合 | 瓶詰め264発売回中16回、6.06%。未瓶詰めの樽は分母外 |
| 2. そのうち刺激0.30以下 | 16/16回、100%。この方針では風味条件による除外ゼロ |
| 3. 5本以上の在庫 | 上の16回すべてで瓶詰め時・在庫観測時に5本以上を確認。常に残っていたという意味ではない |
| 4. 自家販売40本・2発売回 | 全8銘柄が達成。期末も8/8 |
| 5. 条件適合と申し出 | 適格な在庫を持った8銘柄中6銘柄に申し出、75%。適合16発売回のうち申し出時の在庫に含まれたものは6回、37.5%。後者は期間内の重なりで、申し出発生確率ではない |
| 6. 申し出時の在庫 | 適合在庫は生成時・先頭表示時とも10〜11本。6件とも同じ月に初回納品 |
| 7. 申し出から初回納品までの完売 | 0/6件 |
| 8. 月5本上限 | 12発売回・12商品月で上限を観測。その時点の余剰在庫は合計161本、5本単位では150本分＋端数11本。受注や恒久的な売り逃し本数ではない |
| 9. 承諾したが一度も納品せず | 0/6件。途中の「承諾だけ」の操作とは区別 |
| 10. 他店との競合 | 適合24か月品12発売回から計161本を実際に他店へ納品。翌月のデパート用には残らない |

未取扱いで、24か月・刺激・在庫5本・実績などが揃う在庫観測は24商品月。そのうち蒸留がまだ終わっていない観測14、共通待機期間中4があった。両者は重なり得るため、件数を足して原因の割合にはしない。観測は月次前の在庫スナップショットで、すべての判定機会を網羅するログではない。

元の1.35%は、まず長く熟成して瓶詰めした商品自体が少なく、その在庫を月5本の後に他店へ渡す方針の結果と読むのが妥当。元の走行では、刺激条件や申し出後の完売は主因ではなかった。2シードで取扱いが成立しなかったことには判定時期の制約も関わるが、上の重複観測だけで排他的な原因比率は算出しない。

月間上限の161本を「上限を外せばデパートが全部買う」という売上予測には使わない。これは在庫配分の観測であり、追加需要や注文が存在した記録ではない。独立した境界診断でも、36本から5本を納品した後の31本について、次の5本が上限で止まることと、31本すべてが失われた需要ではないことを分けた。

## A・B・Cの比較条件

同じ8シード、初期資金£1,600、最大4樽で240か月ずつ比較した。抽出40・65・90を繰り返し、バーボン／リフィルを交互に使用。抽出時期ごとに朝霞・川霧・石蔵の3銘柄へ発売する。36か月目までは6か月品、その後は12・24・36・24か月を仕込順で割り振る。自家販売を続け、納品の優先順は元の検証と同じとした。

各シードのA/B/Cで、完成発売回の年月・熟成・抽出・樽・風味・本数、仕込数が一致することを検査した。利益差による完成品の製造差は今回なかった。仕掛中の全状態が同一という検査ではない。

| モデル | 比較用の仕様 |
| --- | --- |
| A | 現行条件のまま。現在の販売中在庫から申し出、継続取扱い、月5本 |
| B | 過去発売回でも穏やかな24か月品があれば相談可能。一企画5本で終了。次の企画は新申し出。納品済み銘柄は12か月待つ |
| C | Bの有限企画を使い、12か月ごとに穏やか／力強い／長期／香りの企画を巡回。申し出時の企画条件を固定し、次の発売回でも再検査 |

B/Cでも買取140%、40本・2発売回などの実績条件、既存の共通6か月間隔、店舗全体月5本の安全上限を維持した。企画を承諾しても在庫を予約せず、自家販売や他店納品は続く。期限・強制納品・違約金はない。すべての申し出を受け、納品可能なら渡す固定方針であり、人間の選択行動の予測ではない。

企画の周期と再申し出の12か月は比較の仮定。本編採用値ではない。B/Cは同じ過去発売回を再び選考根拠にできる。この影響も後述する。

### Cの風味条件

基準Aの8シード・352発売回で調整した探索的条件。同じシードで比較しているため、未知シードへの予測性能を検証したものではない。

| 企画 | 比較条件 | 納品件数 | 抽出時期：早め／中盤／後半 |
| --- | --- | ---: | --- |
| 穏やかな熟成酒 | 24か月以上・刺激0.30以下 | 24 | 16／8／0 |
| 力強い一本 | 24か月以上・刺激0.25以上 | 13 | 0／3／10 |
| 長期熟成 | 36か月以上 | 26 | 8／2／16 |
| 香りの特集 | 12か月以上・character 0.88以上 | 29 | 0／22／7 |

仮案の刺激0.40以上は、24か月以上184発売回中1回しか該当しなかった。実測の第75百分位をもとに0.25へ調整した。「穏やか」と「力強い」は0.25〜0.30で重なる相対的な企画条件で、正反対の区分や品質等級ではない。香りはcharacterの第65百分位をもとに0.88とした。現行値は果実香だけを分離しないため「果実香に優れる」とは評価しない。今回の納品は香り企画も含め24・36か月品だった。

既存の全抽出位置を網羅した別の分布検証では、24か月品の86.34%、36か月品の全条件が刺激0.30以下。今回の固定製造方針では78.26%となった。分布と製造方針の分母が違う数字を混ぜない。

### 取引できなかった理由と時期

Aでは1件だけ、適合在庫1本で申し出が届いた。その1本は65か月目に他店へ渡り、同じ関係の初回納品は92か月目まで待った。申し出の在庫条件と最低納品数の違いが、自然な長期走行でも現れた。他22件の初回納品は申し出と同月だった。

B/Cは在庫なしでも相談するため、申し出時に適合在庫ゼロが102/111件、89/105件あった。これは失敗した納品ではなく、将来発売を待つ相談を作った結果である。期末まで未納品の23件・13件は、固定方針下で適合する次の5本が届かなかった未完了相談。辞退・期限切れ・罰則はない。合算した適合在庫が5本以上でも、発売回ごとに5本なければ納品できない。

Bの未完了件数と26か月の待ち中央値は、相談が多ければよいとは言えないことを示す。Cにも最長69か月待つ例がある。新しい管理タスクに感じさせず、相談を終えられること、今は応えなくてもよいことが必要になる。

月上限の在庫観測はAで115発売回・115商品月、在庫曝露合計2,315本月、5本単位では2,085本月分。B/Cは該当観測ゼロだった。一企画を終えると関係が非稼働になるためであり、月上限が存在しないという意味ではない。Cでも別の銘柄の企画が同月に納品されたため「今月の納品を終えました」の見積拒否が1商品月ある。企画不適合や残枠を含む見積拒否の詳細は `diagnostics.json` に残す。

### 在庫の競合と応答遅延

穏やかな24か月以上の商品のうち他店へ渡った本数はA2,640本、B2,792本、C2,645本。デパートの追加購入需要を証明する数ではなく、実際の配分である。Cでも個人商店とスーパーへの流れは残った。Bではデパート納品185本減の全量が一店舗へ移るわけではなく、自家販売も134本増えた。

感度検証として、Aのすべての店舗申し出を先頭表示から2か月待って承諾した。申し出23件は変わらなかったが、先頭表示時の適合在庫ゼロは16件、申し出時の候補在庫が初回納品前に尽きたものは23件だった。後の発売回から全23件に納品できたものの、デパート総数は625→510本、最初の納品は全走行92か月目へ遅れた。

この感度検証はデパートだけでなく全店舗の返答と待機列を遅らせる。デパート単独の返答時間だけの因果効果とは断定しない。月上限だけでなく、店から声がかかる時期と、応える発売回を残せる設計も影響する。

## 銘柄・製法の偏り

Cでは後半抽出が33/92操作（35.87%）選ばれ、Aの21/125操作（16.8%）より比率が上がった。力強い企画では後半10/13、香り企画では中盤22/29、長期企画では後半16/26と選ばれ方が変わる。長期熟成の納品割合もC53/92に対してA52/125だった。固定方針で作られたものの配分なので、プレイヤーが実際に長期熟成や別製法を試したくなることの証明ではない。

1走行で最も多く選ばれた銘柄の本数比率は、A40〜50%、B36.36〜45.45%、C36.36〜45.45%。Cの全8走行で3銘柄すべてに取引があり、一銘柄だけへの集中は起きなかった。ただし銘柄は抽出時期ごとに固定し、プレイヤーが意図的に3銘柄を作る比較条件である。自発的な多様化とは区別する。

再申し出の選考根拠に新しい適合発売回が一つも加わっていなかった例は、B8/111件、C19/105件。過去の適合発売回集合を再利用した数で、同じ発売回を再納品した数ではない。Cも、企画を巡回するだけでは新しい発見を保証しない。次の設計では同じ企画・同じ根拠発売回の反復採用を抑える案を検証する。今回その抑制はシミュレーションしていない。

## 推奨と次段階

Aは現行の基準として機能し、若い・まとまった在庫を他店に渡す余地もある。ただし、継続関係と毎月の高単価買取が中心で、何を評価されたかを記録しない。

Bは有限の選考と相談を最小に実装しやすい。長期在庫を待つ接点は生まれたが、穏やかな酒だけを選ぶ条件と長い未完了相談が残る。最終方向には不足する。

Cは、後半抽出を含む別の個性が異なる企画に合うことを表現できた。納品本数・利益はAより少なくても、銘柄を選ぶ理由と来歴を設計できる。方向性として推奨する。ただし今回の周期・閾値・再利用・長い待ち時間はそのまま採用せず、一企画のBで来歴と任意相談の体験を確かめてから広げる。

店舗の役割比較、採用年月・企画・根拠発売回／実納品発売回の記録、評判倍率を使わない新しい相談、次の最小変更案、試遊項目は [DESIGN.md](DESIGN.md) にまとめた。個人商店も現行では40本・2発売回を必要とするため、「新作・実験作を最初から受け入れる」という目標は未達であり、今回達成したとは扱わない。

## 検証と限界

元の120か月8走行、240か月のA/B/C計24走行、遅延感度8走行の計40走行・8,640か月に加え、条件調整用A8走行・1,920か月を実行した。全走行で4樽制限、在庫保存則、会計、納品と自家販売の分離、店舗別月上限を検査。納品前後で銘柄評判が変わらないことも確認した。既存店舗テスト27件と独立境界診断は通過した。

スクリプトと集計は別担当が独立レビューし、分母、時点、過去選考の再利用、在庫合算の限界を反映した。表現監査では必要な数値・前提・未確認を残し、作品向けコピーは追加していない。LABへの新規登録は不要で、既存の作品入口・名称・探索状態を変えていない。

自動検証できたのは到達・風味分布・在庫・納品・会計・選考の偏りまで。断る自由が気楽か、相談が義務に感じられないか、来歴が嬉しいか、別の企画のために仕込みたくなるかは人間の試遊が必要。本編の新機能やその実機確認、作者による採用、Production公開を完了したものではない。
