# R6 Canvas browser evidence

Baseline: immutable checkout of R5 main `2ff8aba1287f1e7aba7ceb902cfaef5df1c9dd79`. R6 changes no product bytes or URL identities. `tests/r6-browser-lifecycle.mjs` serves that baseline and current worktree under separate prefixes, fixing seed42, system time, Canvas `performance.now`, CSS animation500ms phase, font-ready, viewport and DPR. It records startup runner SHA256 and verifies that the runner remains unchanged throughout both engines.

Configurations: Chromium140 headless shell and WebKit26.5, each 360×568/DPR1,375×620/DPR2,390×680/DPR3,390×680/DPR3 reduced-motion. Full Chrome's singleton UNIX socket is prohibited in the current sandbox; the existing matching Chromium headless-shell executable runs successfully without that singleton. No TLS or sandbox security policy is weakened. The initial launch failure is retained in diagnostics.

The 26 scenarios cover initial distill, preparation modal/confirmation, lever gesture/countdown, active distillation, glass collection, cut bar, integrated result, cask choice and fill, warehouse, inspection, tasting/end, bottling, sales, map (including its separate Canvas hash), ledger, reload, map open across hidden/visible, synthetic persisted pagehide/pageshow, viewport resize and reduced-motion change. Captures include decoded screenshot comparison, full internal DPR Canvas RGBA digest, Canvas tool/arrival state, DOM text/rectangles/hit targets/focus/ARIA, formal state and exact localStorage raw hashes. All comparisons require zero different pixels; no threshold is used.

A test-only import of the exact existing CanvasScene URL wraps queue/draw to count calls and observe the existing instance. It adds no timer and changes no product module. While hidden/suspended, all three existing timers and RAF are cleared; additional requests produce no draw. Twenty consecutive requests produce one RAF. Synthetic `PageTransitionEvent` with persisted=true is explicitly not a real BFCache hit. The root application deliberately pauses/saves on suspend; baseline/candidate equality, rather than universal raw-state immutability, is the lifecycle criterion.

One-hour cache tests keep the same URL prefix and switch serving from old to new bytes across reload. R6 product bytes are identical, so reused cached bodies are valid; fetched bodies, if any, must match exact current hashes. This is an unchanged-version cache compatibility test. The earlier R5 changed-version browser test and the R6 immutable graph/mutation tests provide separate evidence for invalidation propagation. This run does not claim to change a cache version or force unused invalidation.

Two initial harness timing assumptions were corrected before the full matrix: capture frames allow active distillation to advance past progress0, so moving states are compared strictly between baseline/candidate; collection started after progress0, so the harness waits to progress20 before stopping, respecting the real enabled glass control. Product/expected model behavior is unchanged. Diagnostics are retained. The executed final runner is frozen before the matrix.

Limitations: these are fixed animation phase samples, not every frame. Font-ready redraw is used, but a real font-network failure/retry and before-font screenshot are not rerun here. DPR is varied between contexts; a live monitor-driven DPR change is not simulated. Physical iPhone Safari, OS backgrounding, touch feel, VoiceOver audio, nonzero safe-area and real BFCache remain unverified.

Final counts and failures are authoritative in `results.json`; matrix log is `run.log`. Representative375px PNGs are retained; complete capture records include every PNG SHA256 and internal Canvas digest. Full temporary PNGs remain in the runner-created scratch directory, while the repository retains exact hashes and selected images.
