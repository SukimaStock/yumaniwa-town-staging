## 「指…」の原因と対応

`shop-app.mjs` の `staffBrief` が「指示待ち」を生成し、`canvas-scene.mjs` がメニューボタン右の残り幅へ1行で描画していた。帳面・担当者・地図・メニューが並ぶと幅は57 logical pxしかなく、通常フォントで「指…」となる。

この狭い描画だけを廃止。未採用は空、採用後の指示待ち・依頼済み・仕込み中は担当者ボタンの読み上げ名と既存担当者画面で確認する。空き待ち・資金待ち・判断待ちは既存の330px・2行の状態欄へ、正式な `D.canBeginUsual()` の理由とともに表示し、担当者詳細には全文を残す。旧抽出の重要案内の優先は維持。純粋な `staff-status-view.mjs` は表示だけを組み立て、予約・給与・開始判定を変更しない。

## 本数欄の原因と対応

PR #762の `shop.css` のflexより、後から読む `room-scene.css` の `.bottling-plan-fields {display:grid}` が優先されていた。3列へ「ラベル・−・select・＋」の4要素が入り、＋が次の行へ移動した。

限定セレクター `#action-dialog .bottling-plan .bottling-quantity` でグリッドを明示。ラベルは全幅の1行目、−・本数・＋は2行目の45px・可変幅・45px。3部品は高さ48pxに統一。既存の `#action-dialog button {min-height:48px}` も考慮し、読み込み順と継承に依存しない。販売室・手動瓶詰めの数量UIは変更しない。

## 反応文の調査と採用文言

「風味の名前が変わりました。」は `74d845cf`（2026-10-23、PR #618）からある。`flavor-feedback-view.mjs` が保存された連続する `flavor.history[].label` の違いを検出する。新しい味の判定は追加せず、確認できた変更後のラベルを詳細と同じ `uiText()` 表現で **「○○」に変化** と表示する。例: **「穏やかな果実香」に変化**。

「少しずつ、減っていく」は `9631975e`（10-14）の `character.mjs` の正式イベントタイトルで、`4897b055`（10-20）の自由熟成観察、10-23の下部反応にも引き継がれた。今回新しく発生させた文ではない。6か月以上、前の観察から6か月以上、未観察で他の優先観察がなく、`(残量＋既に瓶詰めした量) / 最初の量 <= 0.90`、木の影響 `<0.62` のときの蒸発に対応する。瓶詰めで取り出した分を蒸発と誤認する判定ではない。発生が遅れることもあるので「1割」と固定せず、現在の案内は **蒸発で量が減った** とした。

同じ領域の観察も監査した。既知のeventIdと正式タイトルが両方一致するときだけ現在の文を置換する。保存されたタイトル・履歴は不変。未知のタイトルは既存の表示を維持する。

| 種類 | 現在画面での表示 | 根拠 |
| --- | --- | --- |
| wood | 色が深くなった | 既存の木の影響閾値。従来の短縮表示を維持 |
| fading | かおりが弱くなった | ピークまたは前回試飲からの原酒の個性低下 |
| rough | シゲキが残る | シゲキ>0.55。「強い」の区分を新しく作らない |
| fruit | かおりが強い | 原酒の個性>0.80 |
| rounded | 口当たりがやわらかい | シゲキ<=0.30 |
| loss | 蒸発で量が減った | 部分瓶詰め分を除いた蒸発の閾値 |

前回比較の「香りが落ち着いた」はこの表示内だけ「かおりが弱くなった」、「香りがふくらんだ」は「かおりが強くなった」へ。木の余韻・シゲキの比較は対象が明確なので維持。通常の試飲処理 `shortChange()` 自体は変更しない。最新の事実を1件だけ選ぶ方式、同月の優先順位（風味名→比較→観察）、発生月と翌2か月の表示期限、試飲済みの反応が消える方式を維持する。詳細を開くと下部反応は隠れ、同じ文を重ねて常時表示しない。
