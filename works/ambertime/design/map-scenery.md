# 世界拡張 第5段階：取引によって育つ地図

景色は正式な事実を読む表示であり、保存項目・関係ポイント・経済効果を追加しない。入口は既存の `mapPartnerProjection()`、共通の判定は `mapSceneryProjection(game,stage,partnerProjection?)`。

## 少数の表示ルール

| 表示 | 条件 |
| --- | --- |
| 段ボール1つ | 店舗の正式な取扱関係、または地域の正式契約。申し出だけでは置かない |
| 花1段階 | 確定取引量6本以上、3つ以上の取引月、初回～最終取引の間隔6か月以上 |
| 花2段階 | 確定取引量24本以上、6つ以上の取引月、間隔24か月以上 |
| 蝶 | 契約済みで、最後の確定活動が当月・前月・前々月のいずれか |

取引量・取引月・初回～最終の間隔は累積する値だけを使う。契約からの経過年数だけでは花は咲かない。同月の操作分割や一度の大量取引も継続とは扱わない。花は0/1/2段階で、履歴不明は `null`。不明を0本や継続年数へ変換しない。段ボールは在庫数量ではなく合意の印。蝶は紹介成功や新取引先出現を予告しない。

## 使用する正本

- 町：既存 `shop.deliveries`。通常店舗で明示された棚方式の開始月より後の行は観測済み顧客実売、それ以前は旧卸売。デパートは企画の確定納品。景色用の量・月は確定活動から求め、納品と顧客実売の値は別に返す。
- 配分・取消・現在在庫は取引の成立回数に数えない。棚へ配分後、実際に売れた事実がない間は蝶も生まれない。
- 地域：`totalsByPartner` が量の正本。継続は `regionalDeliveryHistory()` の正式receipt全体から導出し、履歴と累計の一致・契約ID・本数/月を確認する。最近8件は完全履歴ではない。地域の `customerSales` は常に `null`。
- 町の納品帳は上限2048件で追加を止め、古い実績は捨てない。地域の正式操作帳も上限12000で拒否し、履歴を切り捨てない。世代交代はこれらの記録を維持する。

旧データで履歴・棚の境界が欠けている場合、継続は不明として花を推測しない。地域の累計だけ分かる場合は量を保持し、月数を補わない。保持済みの正しい最終納品月が分かれば、その事実の範囲で最近の活動を判断できる。

## 比較例

A：酒店へ10年にわたり取引した記録は花2段階。B：スーパーへ同月1000本でも継続条件を満たさず花なし。C：バーで月1本ずつ25か月の実売があれば花2段階。これらは純粋判定の明示的な試験用納品帳で比較し、本編の経歴だとは扱わない。

本編の自然seed3では、実際の契約から酒店の棚へ45本を配分して120か月進めると、観測済み28本・28取引月・115か月間隔で花2段階になる。残った棚を戻して60か月休むと花は残り蝶は消える。再配分だけでは活動を作らず、次の実売が起きた時に蝶が戻る。

D：自然seed3・6のnear-wide問い合わせから成立した地域契約へ5本を正式納品すると、段ボールと蝶が現れ、花はまだない。その後6か月間隔の取引を重ねれば花が咲く。E：60か月休止しても花は残る。F：正式納品を再開すると蝶が戻る。地域への納品を消費者販売へ読み替えない。

## 描画と性能

`map-scenery-view.mjs` は位置と画素だけを持つ。町・近所の既存bounds、地方窓口 `[86,36,12,12]` の近くの草地に2px単位で置く。既存の背景花とは別の描画由来・色を持つ。建物、道、川、選択枠は塗り替えない。日本・地球には取引先も装飾も作らない。

段ボールと花は既存144px Canvasへ描き、蝶だけを同じ地図レイヤー上の操作不能なSVG/CSSで動かす。パン・拡大に一緒に追従し、選択先が変わっても配置は動かない。M0と日常地図は同じprojectionとrendererを使う。

正式状態がimmutableである既存契約を利用してWeakMapに証拠集計と縮尺別projectionを保持する。同一状態の再表示・カメラ操作・6視点切替で正式操作帳を毎回走査しない。次の正式状態では再導出し、cold restoreでも同じ結果になる。表示用キャッシュは正本ではなく、古い保存を保持し続けない。

`staticKey` は段ボール・花・位置だけ、`motionKey` は蝶の有無。蝶の期限切れだけでCanvasを描き直さず、無関係な資金表示や選択でも再描画を増やさない。蝶はCSSだけで羽ばたき/移動し、専用タイマーを持たない。地図が閉じた時・ページ非表示時に停止、reduced-motionでは静止する。視点・選択・縮尺別カメラ保存は第4段階のまま。
