# AmberTime 本編の画面・テキスト整理

基準: main `a5f4b2da6ea63e0d277e3f1943051cc7832a2e26`。Stagingのみ。製造・経済・保存・素材のモジュールは変更していない。終了した独立試作の再利用・入口追加なし。

| 画面 | 変更 |
| --- | --- |
| 共通 | 所持金・年月・世代と時間状態を集約。常設コピー・版番号・重複見出しを整理。読み上げ用見出しは保持 |
| 蒸留 | 蒸留開始、採取量、刺激・原酒の香り、終了操作を優先。担当者費用を短縮し、蒸留中の重複情報を省略 |
| 樽選択 | 二樽・価格・原酒量は維持。見出しを「樽を選ぶ」に統一 |
| 貯蔵庫・試飲 | 樽一覧と絵を縮小。減少量・最後の試飲を詳細へ。三指標・風味タイプ・風味文・前回の印を保持 |
| 比較 | 二樽・発売回の年数、タイプ、三指標を先に表示。抽出位置・年月・残量・販売実績等は補足へ |
| 瓶詰め | 本数・費用・実行後の所持金・銘柄・実行を優先。外観の折りたたみは維持。短い画面でも操作へスクロール可能 |
| 販売 | 棚を四商品ずつページ送り。ボトルの味は詳細へ。販売先は選択した一店の条件・価格・納品操作を表示。申し出・納品可能件数は閉じた状態でも表示 |
| 製法・担当者 | 製法選択と依頼を分離。支出と抽出位置・樽を先に表示。来歴は「元の記録」から確認 |
| 帳面・保存 | 通常画面は短い入口だけ。帳面・長い記録・設定を既存ダイアログへ。旧版・研究所・初期化は維持。保存を開けない場合も復旧導線を表示 |

## 検証

- `node --test works/ambertime/tests/*.test.mjs`: 既存564件。
- `node works/ambertime/tests/compact-browser.mjs`: Chromium、360×740・390×844・1280×900。幾何位置・タップ領域・前回印・三指標・比較と詳細の往復・入力保持・販売先・棚ページ送り・ダイアログ停止・旧保存・世代交代後を検証。結果と対象ソース・画像hashは [browser-results.json](after/browser-results.json)。
- 保存は公開モデル操作で生成し、厳密な復元を通す。本編と試作の保存キーを分離したまま維持し、画面変更だけで経済や保存結果を変更しないことを確認。
- 表現監査: 操作と重なる説明、常設コピー、不要な見出しを削減。費用・実行不能理由・保存エラー・契約や納品の意味は保持。新しい装飾・素材なし。
- 独立レビューで復旧入口・ページ送りフォーカス・帳面の複製IDを検出し修正。試飲の旧CSSが隠した時間操作の44pxを予約していた点も、原因を限定して修正。

通常文字の主要操作は検証した三画面サイズで到達可能。長い帳面・履歴、製法一覧、開いた味や樽の詳細、複数納品候補、長い銘柄名、文字拡大、低い画面・キーボード相当の短い高さでは必要なスクロールを残す。縦スクロール禁止や固定高による切り捨てはしていない。

実機iPhone Safari、OS文字拡大・実物のソフトキーボード、スクリーンリーダーは未確認。ブラウザでの文字拡大・短いビューポート・キーボード操作の確認と区別する。
