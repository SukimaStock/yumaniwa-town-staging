# 蒸留所の歩み：10年・20年・40年検証

リポジトリのルートから `node works/ambertime/tests/history-simulate.mjs`、または `works/ambertime/` から `node tests/history-simulate.mjs` で再実行できる。`AMBER_OUT=/absolute/path` で出力先を分離する。ブラウザ用の一時保存が必要な場合だけ `AMBER_HISTORY_SAVE=/tmp/ambertime-history-480.json` を指定する。保存データそのものは成果物に含めない。

シード1・初期資金1,600から、公開操作だけで480か月進め、120・240・480か月に検査した。抽出40/65/90を交互に使う3銘柄、バーボン/リフィル樽、最大4樽。36か月までは6か月熟成・2樽で立ち上げ、その後12/24/36/24か月熟成を繰り返す。3回に1回の発売回は6か月間保管し、残りは標準価格で自家販売する。酒店・スーパー・デパートへの納品を行い、港の仕入れ店の通常卸売と特別注文も受ける。条件未達の特別注文は通常卸売を選ぶ。化学・価格・需要・評判の7ファイルのハッシュは基準コミットと一致した。

40年時点で、3銘柄・61発売回・21デパート採用が残った。特別注文は8回受け、4回成立、4回は条件未達を経て通常卸売へ回した。通常・条件未達時の卸売出荷の歩みは22件。自家販売は合計1,453本。歩みのJSONは107,968 UTF-8バイトだった。生成前後の保存文字列は完全一致し、別のNodeプロセスで厳密復元した後の歩みJSONも一致した。10年・20年時点の全出来事の識別子・種類・年月は40年時点でも残り、未来の日付と重複IDはなかった。歩みを確認した後も481か月目へ進めることを確認した。

## 現在の上限との距離

40年の実測値に対する残りは、操作履歴 **10,807 / 12,000**、発売回 **451 / 512**、店舗納品 **1,935 / 2,048**、銘柄 **125 / 128**。これはこの方針・シードの観測値であり、全プレイ方針の40年保証や上限までの年数の外挿ではない。操作回数を増やす価格変更・試飲・納品・取引選択などによって、同じ経過年数でも保存量は変わる。

復元コードの判定は `text.length < 1,500,000 * 4 + 16,384`、すなわち **6,016,384 UTF-16コード単位未満**。バイト数の判定ではない。40年の保存は175,919コード単位で、この上限との差は5,840,465コード単位。`localStorage` の容量制限はブラウザ・他の保存キーの使用量にも依存し、この復元上限とは別である。表のUTF-16換算は保存文字列の長さの2倍であり、ブラウザ全体の実使用量や保存可能容量を保証しない。

`heapDeltaBytes` もCSV・JSONに残したが、10/20/40年で約+19MB/-23MB/-49MBとGCの影響を受けた。これは保持メモリや最大メモリ使用量の測定ではない。歩みのJSONサイズは再現可能なデータ量の指標として別に示す。生成時間も共有実行環境の単発実測であり、端末性能の保証ではない。ブラウザのWorker・初期DOM・年別展開の検証は別のブラウザ結果を参照する。
