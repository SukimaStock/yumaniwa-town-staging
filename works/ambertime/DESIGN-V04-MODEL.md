# AmberTime 0.4 — 一樽と試飲のモデル

## 再利用と変更

`model.mjs` と `parameters.mjs` は変更しない。原酒の抽出幅・樽の種類・既存の熟成係数の個体差から、実際の荒さ、香り、木の影響、蒸発、維持費、瓶詰め・初月販売を計算する。`character.mjs` はこの計算に一樽の進行・試飲・状態判定だけを重ねる。

新しい樽の抽出幅は 0.35〜0.90 の連続値。隣り合うシードを混ぜてから抽出幅・樽種類・既存乱数を決めるため、2本目も近似した同じ原酒にはならない。固定の性格クラス、品質点、未来の最適時期は作らない。同じシードと操作は完全に再現可能。

## 任意の試飲

`sampleJourney` は現在の年月、種類、抽出幅、実際の4性質、既存 `tasting` の3行を保存し、`view=tasting` にする。試飲中 `tick` は何も進めない。選択の最中にも試飲可能で、元の選択は残る。`endTasting` で観察へ戻る。量の減少、追加費用、回数制限はない。同月の再試飲は同じ記録を再利用し、前月以前の比較対象を消さない。

比較は刺激、原酒の香り、木の余韻それぞれについて小さな数値差を短い日本語にする。サンプルは実際にプレイヤーが取ったものだけ。完成記録にはその履歴、前後の印象的な差、棚を移した年月を事実として残す。

## 固定順序ではない節目

最低6か月、前回の節目から最低6か月を空け、その月の状態から未登場の条件を選ぶ。

- 木の影響 0.36以上 → 色が深まり始めた。
- 過去の実際の香りの最大値から 0.035以上低下、または保存した試飲から0.025以上低下 → 香りの移り変わり。
- 荒さ 0.55超 → 若い原酒の刺激が残る。
- 原酒の香り 0.80超 → 原酒の香りが広がる。
- 荒さ 0.30以下 → 口当たりの変化。
- 残量が初期量の90%以下、かつ木の影響0.62未満 → 原酒の印象を残しながら減少を承知で待つ判断。

重なる条件は木→香りの低下→刺激→果実→丸さ→残量の順で優先する。果実を先に確かめた樽では、そのすぐ後に丸さの質問を重ねない。刺激や丸さを先に確かめた樽では、果実の質問を重ねない。似た初期の問いで3回の枠を使い切らず、後の木・香りの低下・残量に判断を残す。条件は一度だけ登場する。3回判断したら、次の通常イベントは増やさず12か月後に最後の判断へ。84か月を超えても最終判断へ進み、あと3か月だけ待つ場合も87か月で必ず完成する。最長4回の主要判断。任意の瓶詰めはいつでも可能。

介入は一つだけ。「涼しい棚」は既存係数を soften×0.88 / wood×0.83 / evaporation×0.86 にし、既存の保存検査が認める0.8〜1.2に収める。木の移り・蒸発を抑える代わりに荒さが抜ける速度も遅くなる。仕込み・樽の費用は既存どおり、架空の化学的ボーナスはない。説明だけ変える分岐ではない。

## 保存契約

一樽形式は version 2。通常のモデル保存はversion 1のまま。`journey-v03.mjs` は旧仕様の凍結コピー。保存済みの0.3一樽は `rules=legacy` で旧条件・旧月次処理を継続し、自由な試飲を重ねる。旧選択と旧完成記録を作り直さない。現在の旧樽が完成し、次を預かると新規0.4ルールになる。以前の蒸留所の別キーにはアクセスしない。

意味のある操作（試飲・判断・任意の瓶詰め）を年月付きで保存する。復元時にはシードから最大87か月の有限リプレイで現在状態と記録を照合する。未知の版、偽造した性質・記憶・選択、途中の不正な状態は拒否する。保存の読み取りだけで上書きしない。試飲を開いたまま復元した場合も、時間は止まったまま。

これは一樽の時間・味・経費・到達可能性の確認であり、長期経営の順位付けや人間の再プレイ意欲の検証ではない。元の0.3同様、次の樽は一樽の独立した費用計算から始まる。旧経営保存は別で維持する。

`tests/character.test.mjs` の12項目で、任意試飲の停止、同月再試飲、選択中試飲、実際の棚移動の代償、異なるシード・操作による分岐、即時瓶詰め、改ざん拒否、0.3互換、旧樽の自由な瓶詰め、3樽連続の記録保持を確認。
